# 七项工作全局框架图

2026-10-11，按用户要求在 Microsoft PowerPoint 界面中使用原生矩形、文本框和箭头手工绘制。

- [可编辑PPTX](mlkem-overview.pptx)：单页，12个原生形状/文本框、9条原生线条，没有嵌入位图。
- [论文用矢量PDF](mlkem-overview.pdf)：PowerPoint导出，单页，宋体与Times New Roman字体嵌入。
- [高分辨率PNG](mlkem-overview.png)：PowerPoint导出，4000×2250像素。

中文明确指定宋体；英文、数字及西文符号指定Times New Roman。左侧为测量、统计、函数插桩、定位和防护复测闭环，右侧为网络噪声、编译器优化和处理器平台三个并列验证维度。图的内容对应[七项实施计划](../../../docs/research/seven-capabilities-20261011/EXPERIMENT_PLAN.md)，是方案框架，不代表七项实验已经完成或通过验收。

建议图注：**图X　ML-KEM-768解封装时间侧信道检测与常数时间防护的整体框架。**（a）通过完整解封装计时、统计分析和函数级插桩定位候选泄露源，并对防护后的实现进行复测；（b）从网络噪声、编译器优化和不同处理器平台三个维度验证方法的稳定性与适用范围。

在论文中优先插入PDF矢量图；需要位图的编辑器可使用PNG。PPTX保留各元素的独立编辑能力，调整布局时应同时核对箭头位置。旧报告与实验原件未修改。
