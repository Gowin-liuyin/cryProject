## 匿名化口径

- 路径与身份只在新文本副本里转换，原始文件不动；数值 CSV 保持原字节；上游许可证原样保留。
- 转换规则见 `build_support.py` 的 `anonymous_text()`，逐条对应：
  本机仓库根 → `[REPOSITORY]`、本机用户 → `[LOCAL_USER]`、远端项目根（含 `~/yhr/Cry`
  短形式） → `[REMOTE_PROJECT]`、远端用户 → `[REMOTE_USER]`、裸主机名 → `[LINUX_HOST]`、
  IP → `[REMOTE_IP]`、作者名/邮箱 → `[PROJECT_AUTHOR]`/`[AUTHOR_EMAIL]`、
  **仓库名（含小写形态与内含它的 SSH 别名）** → `[REPO_NAME]`/`[KVM_ALIAS]`、
  **队友个人机器名**（两台，机型代号那台也属个人设备指纹） → `[LOCAL_MACHINE_A]`/
  `[LOCAL_MACHINE_B]`。
- 报告离线 HTML 的证据链接在包内重写为 `evidence/files/` 下的副本路径（收录的指向
  「包内副本」，未收录的明说「本卷未收录」——不假装有，也不藏）。
- **扫描范围**：`verify_package.py` 逐成员做字节级正则——文本成员（`.md/.json/.csv/.log/
  .sh/.c/…`，**含 `.sha256` 这类文本摘要清单**）、**`.gz` 成员解压后**扫、PDF 成员抽
  **文字层**后扫；**PNG 不做 OCR**（截图文字在渲染前已按同一套规则脱敏，且已逐张人工
  目检过画面）。**校验器脚本本身不再随包分发**，扫描也**不豁免任何成员**；确实扫不到的
  （图片像素、无后缀的 `LICENSE`/`SHA256SUMS`）逐条列在
  `identity_scan.unscanned_suffixes` / `unscanned_suffixless_members` 里。扫描范围写在
  `verify_package.py` 返回的 `scope` 字段里，不假装全量覆盖。
- **`.gz` 成员解不开就算扫描没做完**：包审计直接判失败，不会以「pass」放行。
- 转换是**有限的直接身份处理**，不承诺公开内容无法关联作者。
- **两类计数分开报**：`direct_identity_markers` / `author_identity_hits` 是**作者身份**
  （姓名、邮箱及其本地部分、主机名与用户名、IP、绝对家目录、仓库名与 SSH 别名、KVM
  主机名）这一侧；`teammate_device_hits` 是**队友个人机器名**（含机型代号）这一侧。
  两者都必须是 0——但它们**不是同一件事**，不要把「队友设备名也清零」读成
  「没有作者身份泄露」这一句的证据。
- **日期型运行标签保留**：跨环境复现表里第三台机器那一列写的是**日期**（如
  `20261017`），不是设备名或账号，保留它不指向任何设备；同表另两台机器的
  **机器名**已占位符化。

## 本轮（2026-10-21）改了什么

- 匿名扫描**从「只扫文本后缀」扩到「文本后缀 + PDF 文字层」**，并补上 `~/…` 短形式、裸主机名

- 包内**不再发布 CTest 的临时工作目录**（44 个带随机后缀的构建目录成员已排除，记账在
  `PROVENANCE.json` 的 `skipped_build_workspace_paths`）；
- `PROVENANCE.json` 现在**覆盖全部成员**（`files` + `generated_members`），
  并写明 `expected/` 是「打包时用包内 C 工具现算的复算基准，只检验重建一致性，不是正确性依据」。
