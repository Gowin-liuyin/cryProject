# 无秘密统计验证与效率比较合同 v1

本合同在新实现及确认数据前固定。旧分析器、历史阈值和批次合同不改。
主方向是随机化单位与证据资格；备用方向是相同精确检验的复算效率。仅保留这两项。

## 有限查证及主方向资格

- dudect官方固定dc269651fb2567e46755cfb2a13d3875592968b5，源码自带Unlicense。
  输入接口prepare_inputs/do_one_computation；第一批定裁剪点，后续102个Welch检验，
  当前实现阈值10、至少10000类0记录。不能把一项t检验冒称完整dudect。
  [官方源码](https://github.com/oreparaz/dudect/tree/dc269651fb2567e46755cfb2a13d3875592968b5)。
- RTLF官方固定2497d660e4b23fc9acd21b077a35e82178fcd728，R实现，仓库未发现显式LICENSE；
  不复制代码到分发包。[官方工具](https://github.com/tls-attacker/RTLF/tree/2497d660e4b23fc9acd21b077a35e82178fcd728)。
  USENIX Security2024原论文3.3要求有限方差的iid；九分位数及bootstrap并不自动处理序列依赖。
  同时核对官方勘误：观察到NSS时间差异并不证明可利用攻击，正符合本作品归因边界。
- 成对交换随机化及精确枚举是既有方法，非本作品首创。
  [SciPy官方定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)。

主方向的新增入口只处理4–20个成对单位、相同调用数，声明独立的对内标签交换及无标签影响
后续结果。检验统计量为成对总时间差之和的绝对值，完整枚举2^m种交换，等值纳入上尾，
alpha=0.01。随机化依据不充分时明确证据不足。效应区间另需成对单位iid，不能沿用p值条件。
真实参考后赋独立标签只能作为无秘密零效应控制；合成已知偏移不能称密码泄露。
既有档案不具备这一新随机化合同，仍由原分析器复算，不能补填声明而升级为新确认。

有限查证没有得到超越正确配置dudect或RTLF检测能力的依据；本轮不举行不适用的胜负比较。
主方向仅交付定义、软件验证和资格控制，不宣称统计方法创新。R12主方向继续证据不足。
依本合同转向备用效率比较，不改变主方向目标以宣布胜出。

## 备用方向固定比较

| 项 | 规定 |
|---|---|
| 改善对象 | 无秘密成对数据的精确随机化复算，保持原数据字节与整数尾计数 |
| 强基线 | SciPy1.16.3/NumPy2.3.5 permutation_test，单样本差向量、permutation_type=samples、abs(sum)、alternative=greater、n_resamples=inf、vectorized=True、batch=4096；依赖检查发现尚缺SciPy，必要安装与版本核验另留日志 |
| 候选 | C11整数精确枚举；利用相邻交换状态更新总和，4–20对，差值绝对值≤10^12；不改变检验族、alpha、等值规则或密码实现 |
| 相同条件 | 同一输入文件、相同整数差、全部2^20种交换；无秘密及无新密码调用，禁止漏掉排列、裁样或给候选免费预处理 |
| 主指标 | 完整进程复算墙钟比值候选/基线；包括读取、解析、统计与输出，均用C CLOCK_MONOTONIC外部观察；基线解释器启动成本单独注明 |
| 开发 | 种子202610079001/9002的2个预定合成文件；只校验兼容和固定参数；不以它们作确认 |
| 确认 | 8个新公开种子202610071001..1008，null/effect/ties/drift各两份；每份两方法各3次，顺序交替；原始文件摘要、完整命令、退出码与时间全保留 |
| 必要条件 | 48次全部完成、尾计数与2^20分母逐项相同、原始摘要不变；每份候选3次墙钟均小于同份基线3次；合并运行比值中位数≤0.5；失败或预算不足为证据不足 |
| 误报和检出 | 精确判定完全相同才能谈效率，不把8个任务当误报率或检出率评价；本次不估计两工具的密码检测能力 |
| 成本 | 开发与确认全部记录，整个比较最多300秒，先到停止；外部软件安装/文档制作不混入复算进程指标，实际版本与现成运行环境另记 |
| 不确定性 | 8个文件是有限固定任务，不是独立真实密码总体；逐份范围及3次变化原样报告，不构造总体速度置信区间；KVM结果与本地ARM成本不合并 |
| 否定与失败产出 | 数值不一致、任一任务候选不快、比值>0.5或预算不足，不支持该效率声明；保留程序、所有数据、负结果和R12缺口，不换任务直到获胜 |

该备用比较若成立，仅支持具体精确复算任务的效率增量；不支持首次提出Gray枚举、
密码更安全、检测更灵敏、真实防护闭环或全部竞赛要求达标。外部SciPy只作对照，作品计算入口为C11。
