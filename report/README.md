# 作品设计报告 LaTeX 模板

按 2026 年第十一届全国密码技术竞赛官方 Word 模板（附件二）复刻的 LaTeX 模板，用于 A1-13 复赛作品设计报告。

## 编译

```bash
latexmk -xelatex main.tex
```

只需要 XeLaTeX；编译产物在 `build/`（已忽略，不提交）。

## 字体

模板按官方版式指定字体，缺字体时会自动退回近似字体：

| 用途 | 字体 | 缺省回退 |
| --- | --- | --- |
| 正文 | 楷体_GB2312 四号 | 楷体 KaiTi |
| 一级标题 | 华文楷体 小三 | 楷体 KaiTi |
| 二级标题 | 黑体 四号 | 无 |
| 页眉、基本信息表 | 宋体 | 无 |
| 封面作品题目 | 华文中宋 | 宋体 |
| 西文、页码 | Times New Roman | 无 |

## 版式要点

- A4 纸，上下左右页边距 2 cm。
- 页眉为“全国密码技术竞赛作品设计报告”，9 pt 居中，下加 0.75 pt 横线；封面不显示页眉和页码，从基本信息表页起显示，页码在该页重新从 1 开始。
- 一级标题华文楷体小三加粗，二级标题黑体四号加粗，段前段后各 12 pt、1.5 倍行距。
- 最多只用到二级标题；误用 `\subsubsection` 会直接编译报错。
- 正文楷体四号、固定 24 pt 行距、首行缩进 2 字符。

## 填写

在 `main.tex` 顶部填写编号、题目、日期、摘要和关键词，然后按 `\section`、`\subsection` 组织正文。封面“注意”段和文末的标题说明段在正式提交前删除。

- 封面徽标在 `assets/cacr_logo.jpg`，取自官方模板；如需换路径用 `\reportlogo{...}`。
- 修改版式时改 `a113_report.cls`，正文内容只放在 `main.tex`。
