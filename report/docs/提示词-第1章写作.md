## 四、逐节要求

### 1.1 问题背景与赛题定位（1,000–1,100 字）

**节首句主张**：ML-KEM 解封装的难点不在算法本身，而在“源码级常数时间”与“产物级常数时间”之间那条容易被忽略的缝。

必须写到：

- ML-KEM（FIPS 203）由 CRYSTALS-Kyber 标准化而来；解封装在 FO 变换下要执行解密、重加密、比较与隐式拒绝；任何依赖秘密的分支、访存或可变时延指令都可能把信息投射到时间上。引用 `fips203`、`kyber2018`、`guo2020`、`kyberslash`、`clangover`。
- 四个困难，每个 2–3 句：① 效应极小（M1 约 32 ns，占 57 µs 的 0.06%）；② 源码级常数时间不等于产物级（clangover）；③ 单一工具不可靠（dudect/RTLF 只回答可区分性，Memcheck/Microwalk 只回答定位，Binsec 只回答有界性质）；④ “未检出”常被误读为“常数时间”。
- 本题 12 条要的是“检测—定位—防护—复测”闭环，不是密钥恢复；本作品只做到“可区分性”，不做密钥恢复。
- 结尾落到主线句：**源码级常数时间不等于产物级常数时间；时间侧信道结论必须绑定编译产物、分层登记、按检测预算表述。** 这句话在本章只出现一次，后面 1.4、3.5、5.1 用不同句式推进。

不要写：后量子密码的宏观背景、量子计算威胁的长篇科普、文献综述流水账。

### 1.2 威胁模型与攻击面（1,000–1,100 字）

**节首句主张**：本作品评估的是本地白盒攻击者：有源码、能编译、能重复调用、能读完整解封装耗时，但看不到私钥、共享密钥与内部验证标志。

必须写到：

- 表 1：评估者能力、秘密对象、可观测量、不观测的量、攻击目标、范围之外。表注首句：“本地白盒、可重复计时、不做密钥恢复。”
- 观测方程：`T = T0 + δ(secret) + noise`。解释三项：`T0` 是公开路径的基线，`δ` 是秘密相关差异，`noise` 是调度、频率、缓存与后台进程。不要用代码表达式，写成文字公式即可。
- 框 1：攻击可行性对照（5 行：M1 分支、M2 除法、M3 查表、M4 提前返回、M5 阴性）。每行写“攻击者需要什么 / 本作品做到哪 / 离密钥恢复还差什么”。框注首句：“本作品只判断可区分性，不进行密钥恢复。”
- 本地与远程的分界：本地锁频下 32 ns 可区分，不等于远程可观测；远程还要叠加协议栈、排队、链路抖动；本作品只做同机模拟，并给出检测预算。
- 明确范围之外：真实远程、其他架构的计时层、功耗/电磁/故障注入、密钥恢复。

不要写：把攻击者写成“可以为所欲为”；把“可区分”写成“可恢复密钥”。

### 1.3 作品功能与系统组成（900–1,000 字）

**节首句主张**：平台由五个被测对象、四个共享层和一条四段链组成；它的功能不是“跑工具”，而是把每次运行绑定到对象、产物、环境和判定。

必须写到：

- 六项功能各 1–2 句：统一输入生成、受控测量、统计检测、函数级定位、防护与审计、可复现。
- 五模块三类：M1/M2 真实历史案例；M3/M4 人工校准；M5 阴性对照。每个模块一句话，不展开结果。
- 四个共享层：计时入口、锁频控制器、统计与功效、定位工具与结果登记；四段链：检测→定位→防护→复测。
- 框 2：工作量总览（按 `04` §五 的 11 行：5 对象、9 工具、90 格、177 次运行、每类 10000×3、12+12 格、5 档网络、263 项测试、128/1048 审计、4 家族/21 成员、quick/full）。框注首句：“工作量不在跑了多少次，而在每次运行都能被追溯到对象、产物、环境和判定。”
- 引用图 3（平台总体架构，2.3 节）时只写“总体架构见图 3”，不提前展开。

不要写：把五个模块各讲一遍“问题—测量—结果—修复”；那是第 3 章的事。

### 1.4 主要工作与创新点（900–1,000 字）

**节首句主张**：本作品不提出新的检测原语，也不主张发现新漏洞；它的贡献是把已有工具组织成一套以产物为中心、可审计、可分层的证据流程。

必须写到四条创新，每条给一句**定位句**（与 `02` §3 逐字同义），后面 2–3 句解释“相对谁、改了什么、为什么不显然、代价是什么”：

1. **分层证据模型**：机制存在、热点可测、端到端可测、防护有效四层登记；每个“未检出”附 MDE。证据：表 2/9/10。
2. **预注册与可审计锁频协议**：采集前冻结计划，控制器校验计划摘要，20 次探针与恢复核对；锁频的价值是确定性，不是降噪。证据：2.5、表 12。
3. **多工具交叉与 90 格排查**：9×5 矩阵、3×5×6=90 格；发现 `272125f` 残留同源分支；这是历史产物观察，不是新漏洞。证据：3.5、3.12。
4. **产物与环境的依赖对照**：12 格优化、12 格 aarch64、3 台 WSL2、5 档网络；同一源码在不同产物上结论不同。证据：3.10、3.11。

不要写：“首次”“创新性地”“填补空白”“我们的方法更先进”。不要写“发现新漏洞”。

### 1.5 关键结果与性能概览（600–700 字）

**节首句主张**：五个模块在同一套测量与统计规程下给出了分层结论：M1 测得出修得掉，M2 定位阳性计时阴性，M4 闭环，M5 未误报。

必须写到：

- 表 2：五模块分层结论（对象/角色、定位层、完整解封装计时层、防护后）。数字用 `01` A-01–A-08；表注首句：“未检出指观测效应小于该预算下的 MDE，不等于常数时间证明。”

- 结尾指向第 2 章：“方法见第 2 章，证据见第 3 章”，不展开。

不要写：把表 2 的每个数字再解释一遍；不要重复 3.3 的逐模块叙述。
