# 得分点、差异点与亮点映射

- 依据：附件 `（A1-13）ML-KEM 解封装实现的时间侧信道检测与常数时间防护 2.docx` 与仓库 `docs/reference/official-2026/A1-13-original.docx` 逐字一致；官方未给分值权重，本文件按“基础分—差异分—亮点分—文档分”四层组织。
- 用法：写每一节前先看本表；每个得分点至少有一句主张、一个数字、一个表/图、一个证据落点。没有证据的“亮点”不写。
- 总判断：这个项目的优势不是“发现了一个新漏洞”，而是**同一条题面要求，别人做到一层，我们做到三层**：功能层、产物层、统计层；再加环境边界与可复算。
