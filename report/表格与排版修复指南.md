## 需要手动批量修改的项目

### 1. 表格第一列（项目名/维度名）改为居中

**原格式**（所有表格）：
```latex
\begin{tabularx}{\textwidth}{|>{\raggedright\arraybackslash}p{3.0cm}|...}
```

**修改为**：
```latex
\begin{tabularx}{\textwidth}{|>{\centering\arraybackslash}p{3.0cm}|...}
```

**适用表格清单**：
- 表1.1 威胁模型与评估边界（`ch1.tex` 第69行）
- 表1.2 工作量总览（`ch1.tex` 第118行）
- 表1.3 五模块分层结论（`ch1.tex` 第178行）
- 表1.4 赛题要求完成度总览（`ch1.tex` 第204行）
- 以及所有后续章节的表格

**全局替换命令**（在 `report/` 目录下执行）：
```bash
find chapters -name "*.tex" -type f -exec sed -i.bak 's/{|>{\raggedright\arraybackslash}p{[0-9.]*cm}|/{|>{\centering\arraybackslash}p{&}|/g' {} \;
```

注意：这个命令只改第一列。如果表格有多列且第一列宽度不同，需要手动调整。

根据你提供的截图，问题主要出在：
- 图2.2《同一份源码经过编译器得到不同的产物形态》
- 图3.1、图3.2
- 图4.1、图4.5、图4.6

**检查方法**：
```bash
cd report/assets/plots
ls -lh *.pdf  # 确认所有图都是矢量PDF，不是位图
```

**修复方案**：

#### 对于TikZ绘制的图（`.tex`文件）：

1. **文字与边框重叠**：增加node间距或缩短连接线
   ```latex
   % 原来：
   \node[box] (A) {文字};
   \draw (A) -- (B);
   
   % 改为：
   \node[box] (A) {文字};
   \draw (A) -- ++(2,0) -- (B);  % 加长水平距离
   ```

2. **标签文字互相重叠**：调整label位置
   ```latex
   % 原来：
   \node[label=right:{标签}] (A) {};
   
   % 改为：
   \node[label={[xshift=5pt]right:{标签}}] (A) {};
   ```

3. **字号过小模糊**：统一设置最小9pt
   ```latex
   % 在TikZ图开头加：
   \tikzset{every node/.style={font=\footnotesize}}  % 至少9pt
   ```

#### 对于外部工具生成的图（Python/R等）：

重新导出时设置：
```python
# Matplotlib 示例
plt.rcParams['font.size'] = 10
plt.rcParams['axes.labelsize'] = 10
plt.rcParams['xtick.labelsize'] = 9
plt.rcParams['ytick.labelsize'] = 9
plt.tight_layout()  # 自动调整防止文字裁剪
plt.savefig('fig.pdf', dpi=300, bbox_inches='tight')
```

## 一键批处理脚本

创建 `fix_tables.sh`：

```bash
#!/bin/bash
# 在 report/ 目录下运行

echo "1. 备份原文件..."
cp -r chapters chapters.backup.$(date +%Y%m%d)

echo "2. 修复表格第一列居中..."
for file in chapters/*.tex; do
  # 只修改第一列（最常见的3.0cm、2.6cm、0.8cm宽度）
  sed -i.tmp 's/{|>{\\raggedright\\arraybackslash}p{3\.0cm}|/{|>{\\centering\\arraybackslash}p{3.0cm}|/g' "$file"
  sed -i.tmp 's/{|>{\\raggedright\\arraybackslash}p{2\.6cm}|/{|>{\\centering\\arraybackslash}p{2.6cm}|/g' "$file"
  sed -i.tmp 's/{|>{\\raggedright\\arraybackslash}p{0\.8cm}|/{|>{\\centering\\arraybackslash}p{0.8cm}|/g' "$file"
  rm "$file.tmp"
done

echo "3. 查找所有表注..."
grep -n "\\\\par\\\\smallskip{\\\\footnotesize 表注：" chapters/*.tex > 需要手动改写的表注.txt

echo "4. 完成！请手动处理：需要手动改写的表注.txt"
echo "   然后运行: latexmk -xelatex main.tex 测试编译"
```
