# 真实参考时间的后赋标签控制 v1

在新程序及结果之前冻结，继续已有统计资格主方向的补证，不改变旧确认集、阈值、
效率合同或有限模型校准；不新增密码调用、秘密机制计时、攻击或密钥恢复。

输入固定为native-final-20261007/performance中六份ordinary-reference-block1..6
原CSV及同名meta/cost。每份3000条全部读取并验证完整资格；只有原序号0..23用于
此项控制，依次组成(0,1)…(22,23)十二对。其余记录保留，不能挑选类别、耗时或长尾。
这24条并非新的密码采集，原CSV不变；冻结输入摘要另存本合同同名清单。

每个块的时间差d_j固定为原第2j条减第2j+1条耗时。后赋标签的控制模型独立、等概率
交换每一对，只更换符号，不添加偏移、不更改时间、不按秘密或原密文类别赋标签。
完整计算2^12=4096种后赋标签，六块合计24576份条件数据。观测时间可以相依，
控制的随机化来自采集完成后的标签；本计算没有宣称采集时实施过独立随机处理。

检验沿用abs(sum)、全部4096种交换、上尾包含等值、alpha=0.01；候选仍用原C整数入口。
独立数值核验以普通二进制标签、十二项重新求和构造4096项分布，排序后按包含等值的
下界秩给出尾计数，不共享候选Gray更新，也不把有限幅度卷积模型套给真实时间。
每份保存十二个有符号差、候选/独立尾计数、分母、全零及原始拒绝。每块保存被选时间
和原序号、源CSV/meta/cost摘要及条件拒绝数；全零及重复值保留在分母中。

通过条件：24576份候选与独立核验逐行一致，六块各4096份完全保留；每块条件拒绝数
不超过40，即有限标签模型内的误拒绝概率≤0.01；全部输入摘要前后不变。全零不被
解释成有检验能力。任何缺成本、坏输入、覆盖、数值不一致或预算不足都保留部分产物，
不得发布complete，不更换块、索引或alpha取得通过。

外部核验沿用SciPy1.16.3/NumPy2.3.5的正确精确成对交换配置，对每块标签0、1、2047、
4095固定24份数值核验。它们是预定审计行，不是另一次独立概率确认。依赖未就绪或
失败保留，不调版本/参数直到结果有利。核心校验和计时在C，外部软件只作独立对照。

执行在已授权原生x86_64 Linux/KVM；CPU及编译工具先核对，纯CPU小规模枚举无需GPU。
C任务预算120秒：自开始到原始记录关闭，含读取、核验、全部计算与记录I/O；最终
摘要及状态发布另列。外部24份审计预算60秒；安装、构建、软件检查及文档制作另列。
输出目录独占，固定运行源码、编译条件、实际程序摘要、完整记录、成本及失败材料封存。

结果至多支持：在这六份固定真实参考时间上，后赋独立标签模型的条件错误控制及整数
实现正确。它不是实际密码类别差异、秘密泄露、采集序列独立性、真实密码总体误报/
检出校准或防护效果证据；不补成R04、R05–R07或整个作品的全部验收，不作为R12新胜负。
