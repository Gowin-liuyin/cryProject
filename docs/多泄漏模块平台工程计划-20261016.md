# cryProject 多泄漏模块检测平台工程计划（2026-10-16）

面向 CACR 2026 A1-13：把已做成的 clangover 一条链，扩展成「统一测量/统计框架 + 多泄漏模块 + 多检测工具」的平台。  
原则：**不做密钥恢复当交付**；每个模块走检测—定位—修复—复测；人工夹具必须标明「人工构造」；结论限定编译器/ISA/路径。

当前基线（已 push）：`main @ 4a3a4ab`  
- 模块 M1（clangover）已闭环；R02/R04 在限定范围内关闭。  
- 仓库：https://github.com/Gowin-liuyin/cryProject.git

---

```
共享层 Shared Core
  锁频计时 · CSV 协议 · Holm 族管理 · RESULT 模板 · ENV 快照
```

交付叙事一句话：  
**同一套高精度测量与多重比较框架，挂载 4 类泄漏检测模块 + 1 个恒时阴性对照，用开源统计/定位工具交叉验证；主阳性为真实 CVE 路径，人工夹具仅作校准。**

## 1. 共享层（所有模块必须复用）

| 能力 | 现状 | 规范位置 / 要求 |
|---|---|---|
| 锁频测量 | ✅ | boost 关、performance、固定 ~4.30 GHz、taskset、进出频率快照 `restore_match=yes` |

| CSV 类对协议 | ✅ | `message-zero` / `message-ones` / `valid` / `random` / `bit-flipped`；模块可扩展自己的类对，但列名统一 |

### M2 — 秘密相关除法 / 可变时指令（优先下一轮）

| 项 | 内容 |
|---|---|
| 机制 | 对秘密分子做公开分母除法（`idiv`/`div` 等），指令延迟随操作数变化（KyberSlash1/2） |
| 真实案例 | 多库曾中招；liboqs Kyber 路径：KyberSlash1 约 2023-12-15 修，KyberSlash2 约 2024-01-08 修 |
| 建议钉版 | **先做版本审计**：在 `0.9.0`（或 libraries 页标注仍含除法的 tag）与 `0.9.2`/`0.10.0` 修后之间做未修/已修对照；以反汇编出现 `idiv`/`div` 且操作数来自秘密缓冲为准 |
| 主类对 | 设计「除法操作数分布可区分」的两类密文/消息（按论文类对思想；**不做密钥恢复**） |

## 5. 分阶段工期（复杂工程，按优先级）

### Phase A — 平台骨架（0.5–1 天）

1. 落地本文与 `docs/platform/ARCHITECTURE.md`（可从本文精简）。  
2. `third_party/REPOS.md`：clone RTLF/dudect/ctgrind/Mona/Microwalk，记 commit。  
3. 统一 `scripts/run_stats_battery.sh`：输入两类 CSV → 输出 CI + RTLF + dudect +（可选）Mona 一行。  
4. 统一 `templates/MODULE_RESULT.md`。

### Phase B — M2 KyberSlash（3–5 天，优先）

1. 版本审计：在 nss-marker 上对 liboqs `0.8.x`–`0.9.1` 逐 tag 反汇编 `poly_tomsg`/`poly_compress`，找到仍含秘密 `idiv` 的钉版 + 修后钉版。  
2. 构建打补丁的 Valgrind；poison 秘密；未修应报 varlat，已修应消失。  
3. 冻结 PLAN → 锁频端到端 + 可选微基准（只包除法热点）。  
4. 写 M2 RESULT；更新平台总表。

### Phase C — M5 阴性（1–2 天，可与 B 部分重叠）

1. 接入 mlkem-native；同锁频规程、同类对。  
2. 全套工具期望不误报；若误报，分析是工具噪声还是实现问题，如实写。

### Phase D — M3 访存校准（2–3 天）

1. 人工 LUT 夹具 + 开关。  
2. Microwalk（有 Pin）定位到查表站点；ctgrind 交叉。  
3. 统计电池；总表更新。

### Phase E — M4 比较 + Binsec（2–3 天）

1. memcmp vs ct_memcmp 夹具。  
2. Binsec 对抽出函数 `-checkct`。  
3. 端到端统计；总表更新。

### Phase F — Mona 对照 + 报告同步（1–2 天）

1. Mona 对 M1/M2 主 CSV 出对照行。  
2. 更新 `deliverables/`、`docs/full-work-progress.md`、正式报告「检测/定位/修复/复测」章与平台矩阵图。

**合计量级**：约 10–16 人日裸金属工程（不含报告润色）。可两人并行：一人 M2+M5，一人 M3+M4。
