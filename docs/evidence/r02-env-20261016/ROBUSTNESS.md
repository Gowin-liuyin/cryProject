## 2. 方法与规则

四种方法（Δ 一律定义为 class0 减 class1）：

| # | 名称 | 点估计 | 区间 | 说明 |
|---|---|---|---|---|
| ① | 全样本 Welch（**对照基线**） | `mean(class0) − mean(class1)` | 解析正态近似，z=1.959963984540054，SE=√(s₀²/n₀+s₁²/n₁)，方差除数 n−1 | 与 `scripts/platform_stats/stats_csv.c:207-208`、`src/timing_statistics.c:116-118` 冻结口径逐位一致 |
| ② | p99.9 截尾均值差（**族外**） | 两侧各截 0.1% 后的截尾均值差 | bootstrap 百分位 95% | n=10000 时 k=⌊0.001·n⌋=10，保留 9980 |
| ③ | 中位数差（**族外**） | `median(class0) − median(class1)` | bootstrap 百分位 95% | — |
| ④ | Hodges–Lehmann 位置差（**族外**） | 全部 n₀·n₁ 个成对差的中位数 | bootstrap 百分位 95%% | 整数格点二分，精确求解 |

bootstrap 为**分组内独立重采样**（各组按原样本量有放回），B=2000，每个类对固定种子 `20261016 + 序号`；换种子重跑见 §6。截尾、样本量下限、缺失/零值规则见 [OUTLIER_RULES.md](OUTLIER_RULES.md)。

翻转判定：`CI 是否含 0` 与①不一致即记为该方法的翻转；本页不重算 Holm、不改任何 p 值。

### 6.1 两类翻转的性质不同，不能合并叙述

**第一类：均值检不出、位置量检出（M2 的 5 个成员 + M2 s1 对照）。**

这类数据（M2/M5/M3）的耗时分布有很重的右尾：单次运行的样本标准差 443–1532 ns，而类间均值差只有 10–22 ns，所以均值差的标准误被长尾抬高，成员级均值检验普遍不显著。中位数与 HL 只看中心，标准误小得多，同样的中心位移就能被分辨。这与平台 README §5 已发布的**臂级描述性合并**方向一致（unfixed +12.35 [2.98, 21.71] 不含 0；fixed −11.20 [−24.56, 2.15] 含 0）：也就是说，**冻结家族之外的描述性合并早就给出过同一方向的读数**，本页没有发现新信号，只是换了一族更有功效的位置量。

**第二类：位置量失效（M4 的 5 个 + M5 s1 对照）。**

M4 夹具的耗时只有 20–30 ns，落在时钟粒度附近；10000 个样本挤在少数几个整数 ns 值上，中位数差恰为 0、HL 恰为 0，bootstrap 区间必然含 0。这**不是**「效应不存在」，而是秩/分位方法在这种量化粒度下没有分辨力；同族的截尾均值在 M4 vulnerable 主类对上仍稳定地不含 0（−4.10 / −3.98 / −3.86）。M5 s1 对照则相反：均值差 −15.73 由尾部驱动，中心位置差为 0。

## 8. 边界

- 本页是**族外稳健性描述**，不是新的假设检验家族，也不是恒时证明；「未拒绝」与「未检出」都不等于恒时。
- 三种稳健方法一律**不进 Holm**，不改 `stats/holm/holm.csv.gz`，也不改任何 PLAN。
- M3、M4 是**人工构造校准**夹具，不代表上游 CVE；M4 的 vulnerable 只针对人工提前退出夹具。
- 族外对照与 M1、R03 的读数**不进 Holm**，不用于新增或削弱任何声明。
- bootstrap 区间依赖重采样假设；本页只报告点估计与百分位区间，不做多重比较校正，因此**不能**用「12 个翻转」反推总体误报率（未校正、且各方法高度相关）。
- 各 run 的 `.meta` 里 `frequency_control=not_configured` 是采集件固定字符串；锁频事实以控制器落盘记录为准（见 [ENV_TABLE.md](ENV_TABLE.md)）。
