# T08 异常样本与稳健性规则（2026-10-16）

本文件规定本轮（R02/T07—T09）**如何处理异常样本**，以及在主分析之外允许做哪些
敏感性分析、这些分析对已冻结结论有什么影响。规则在写这份文件时**已经执行完毕**
（见 §5 核验表），不存在"看结果再定规则"。

## 1. 主分析：保留全部样本，不删任何长尾

### 1.1 直接依据

[`docs/timing.md` 第 34 行](../../timing.md)逐字规定：

> 普通长尾全部保留。采集阶段不做离群值删除、均值代替逐次数据、自动安全判定或统计泄露判断。

同一口径在仓库其他位置重复出现，互不冲突：

| 位置 | 逐字内容 |
|---|---|
| [`docs/statistics.md:31`](../../statistics.md) | 不删除离群值，不裁尾，不做任何平滑。 |
| [`docs/acceptance.md:331-333`](../../acceptance.md) | CLOCK_MONOTONIC单位ns，clock_getres及观察最小正步长均1000ns；空窗平均15、16、20ns，多为零量化值，不代表单次相同精度。每次10000读钟增量和1000空窗原值保留，不扣开销、不插值、不删普通长尾。 |
| `docs/evidence/platform-collection-20261016/stats/*/RESULT.md` **第 7 行**（45 个 `stats/` 子目录中：`members/` 无 `RESULT.md`，42 个逐字含该句，`holm/` 与 `holm-descriptive/` 是家族汇总另有措辞） | 原始 CSV 完整保留；主 CI 与 RTLF 无删尾。上游 dudect 自带预热、端点丢弃、裁剪与高阶检验单列记账。 |

**因此本轮主分析（以及 T09 的第 ① 种方法）不做任何截尾、不做离群值删除、不做插值、
不做平滑、不扣读钟开销**：冻结家族成员一律用**全样本**的 `n0=10000 / n1=10000` 原值。

### 1.2 主分析统计量（冻结，不因本轮改变）

四个家族的成员定义与判定统计量在提交 `efca8a1` 冻结，本轮**没有**重算、没有替换、
没有补充成员：

- 成员：在一次 run 的一个臂内，对主类对做一次双侧 Welch 大样本正态近似参数检验；
- Δ = `mean(class0) − mean(class1)`；SE = `√(s₀²/n₀ + s₁²/n₁)`，方差除数 `n−1`；
- 95% 区间 = Δ ± `1.959963984540054`·SE（对应 `scripts/platform_stats/stats_csv.c:207-208`）；
- 家族 α = 0.05，Holm 校正，输出在 `stats/holm/holm.csv.gz`。

## 2. 敏感性分析规则（**一律族外**）

只有在**不改变任何主分析输入**的前提下才允许做的三种位置/均值方法。规则如下。

### S1 p99.9 截尾均值差

| 项 | 规则 |
|---|---|
| 截尾比例 | 每侧 0.1%（合计 0.2%），即 p99.9 截尾 |
| 截掉的样本数 | `k = floor(0.001 × n)`（向下取整，不做四舍五入） |
| 保留区间 | 升序排序后取下标 `[k, n−k)`，即掐掉最小的 `k` 个与最大的 `k` 个 |
| 点估计 | `mean(class0 截尾后) − mean(class1 截尾后)` |
| 区间 | bootstrap 百分位 95% |
| 样本量下限 | 截尾后**每组**须满足 `n − 2k ≥ 1000`；不满足则该方法记 `n/a` 并登记，不退化为"少截一点"或"换成不截尾" |
| 本轮实际 | n=10000 ⇒ k=10，截尾后 9980/9980（64/64 个类对全部满足下限） |

**为什么是 0.1%**：样本预算固定为每类 10000，0.1% 恰好等于 `k=10`，是**能给出整数、
可复算、且在预算内不至于削掉分布主体的最小档**。它只用于检查"结论是否被极端长尾撑起来"，
**不是**主分析口径。

### S2 中位数差

| 项 | 规则 |
|---|---|
| 点估计 | `median(class0) − median(class1)` |
| 区间 | bootstrap 百分位 95% |
| 样本量下限 | 每组 `n ≥ 100` |
| 不做插值 | 直接取排序后的中位；偶数样本量时取中间两个的均值（与既有分位口径一致，不使用平滑核） |
| 已知边界 | 计时值量化为整数 ns，[`docs/statistics.md:55-56`](../../statistics.md) 已规定："秩检验对这种量化更稳健，但不能把量化后的中位数差当作真实差的精确估计。" 本文件沿用该警告：S2/S3 的点估计只能读作**量化格点上的位置差**，不得当作物理时间差的精确值 |

### S3 Hodges–Lehmann 位置差

| 项 | 规则 |
|---|---|
| 点估计 | 全部 `n₀ × n₁` 个成对差 `xᵢ − yⱼ` 的**中位数**（HL 位置平移估计量） |
| 实现 | 在整数格点上二分求解第 `⌊N/2⌋`、`⌊N/2⌋+1` 个次序统计量（`N = n₀n₁`，偶数取两者均值）；二分计数用 `searchsorted`，**精确**，不做近似采样 |
| 区间 | bootstrap 百分位 95% |
| 样本量下限 | 每组 `n ≥ 100` |
| 与 S2 的关系 | 结果相同则说明分布近似对称平移；本轮多处 S2=0 而 S3≠0（或反之），说明**并列值极多**，两者不可互相替代 |

### S4 bootstrap 规则（S1/S2/S3 共用）

| 项 | 规则 |
|---|---|
| 重采样方式 | **分组内独立**有放回重采样，每组重采样到原样本量 `n₀`、`n₁`（非配对、非分层） |
| 重复次数 | `B = 2000` |
| 随机数发生器 | `numpy.random.default_rng`（PCG64） |
| 种子 | 固定 `20261016 + 该类对在清单中的序号`；换种子重跑见 [ROBUSTNESS.md §7](ROBUSTNESS.md) |
| 区间 | 百分位法，取 2.5% 与 97.5% 分位（不做 BCa、不做偏差校正） |
| 同一批重采样 | 三种方法共用同一批重采样，避免方法间比较混入不同随机噪声 |

### S5 缺失值与零值

| 情况 | 处理 | 本轮实际 |
|---|---|---|
| `elapsed_nanoseconds = 0` | **保留**在原值序列里（它是真实观测，不是缺失）；单独计数并报告 | 64/64 个类对均为 `zero=0/0` |
| 字段为空 / 非数值 / 无法解析 | 该行**剔除**，按类分别计数并在 `robustness.json` 登记；不插值、不填补 | 64/64 个类对均为 `missing=0/0` |
| `input_category` 不是本次比较的两个类 | 不进入该对比（等价于冻结电池的 `excluded_other_category_count`） | 见 §5 |
| 样本量低于下限 | 该方法记 `n/a`，整个类对状态记 `insufficient_samples`，**不静默替换方法** | 0 个类对触发 |
| 无穷 / NaN | 视为不可解析，按"缺失"处理并计数 | 0 次 |

> 注：`.meta` 里的 `zero_elapsed_count` 是采集件自己写的；本轮按原始 CSV **重新计数**，
> 与 `.meta` 一致（全为 0）。剔零会改变均值，本轮**不做**。

## 3. 三条边界声明

### 3.1 对已冻结 Holm 家族的影响：**无**

- 族内成员仍然是**全样本 Welch / 正态近似 CI**（§1.2），不是截尾均值、不是中位数、
  不是 HL、也不是秩检验。
- 四个家族的成员表（`stats/members/members.csv.gz`）、Holm 输出
  （`stats/holm/holm.csv.gz` 的 `raw_p`、`rank`、`threshold`、`adjusted_p`、`reject`）
  与「描述性分层」（`stats/holm-descriptive/`，本身**不是**独立家族）本轮**逐字未改**。
- S1–S3 一律**不进** `holm.csv`，也不与主类对合并成新家族（与各 PLAN 的
  「对照类对不分进 `holm.csv`」同一条纪律）。
- 不因 S1–S3 的结果增样、追加 seed、补跑、换类对、改顺序或改阈值。四份 PLAN 逐字规定：
  「**不得**因显著性或未显著而增样、追加 seed、补跑或挑选成功进程；不得看到结果后换类对、
  改顺序、改阈值」（[M2 PLAN:238](../m2-kem-20261016/PLAN.md)、[M5 PLAN:202](../m5-completion-20261016/PLAN.md)、
  [M3 PLAN:239](../m3-completion-20261016/PLAN.md)、[M4 PLAN:292](../m4-completion-20261016/PLAN.md)）。

### 3.2 三角色标签（引用时必须带）

| 标签 | 适用对象 | 含义 |
|---|---|---|
| 主类对（进 Holm） | M2/M3/M5 的 `message-zero`−`message-ones`；M4 的 `mismatch-first`−`mismatch-last` | 预注册家族成员 |
| **族外、不进 Holm** | M2 `malformed-zero-tail`−`malformed-ff-tail`；M3/M5 `bit-flipped`−`random`；M4 截断对照；M1 两臂；R03 的 `valid`−`malformed`、`valid`−`truncated` | 只作描述性/链路灵敏度读数 |
| **人工构造校准** | M3 的 LUT 开关臂、M4 的提前退出比较夹具 | 人工构造，不代表上游 CVE |

M1（liboqs 0.10.0 历史锁频，`m1_liboqs010_locked_v1`）本节按**族外**处理：
它没有进入 `efca8a1` 冻结的 Holm 家族，本轮只把它登记为主类对读数，**不新开家族**。

### 3.3 不得升格

- S1–S3 的"不含 0"**不构成**恒时证明、不构成泄漏认定、不构成新的家族拒绝。
- S1–S3 的"含 0"**不构成**恒时证明（"未检出"≠"恒时"，与各 PLAN、平台 README §6 同一条）。
- 本轮对同一样本集做了多组比较且**未做**多重比较校正（因为它们是族外敏感性检查），
  因此**不得**用翻转条数反推总体误报率。详见 [ROBUSTNESS.md §8](ROBUSTNESS.md)。
