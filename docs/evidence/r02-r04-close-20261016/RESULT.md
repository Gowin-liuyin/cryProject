## 3. R02 与 R04 最终判定结论

根据题面原文尺度、已完成的完备环境控制、多工具交叉验证、Holm 多重比较校正以及跨种子、跨物理核心的两轮独立复测证据：

### **R02 结论：关闭**
- **理由**：
  1. 已在裸金属 AMD Ryzen 9 9950X（Linux 6.17.0，Clang 18.1.3）上建立了高精度（纳秒级分辨率、包含原子屏障与时钟步进检验）的解封装时间测量框架；
  2. 处理器、操作系统、编译器、优化选项（`-Os -fno-vectorize`）、频率管理规程（关闭 boost、固定 4.30 GHz、预探针与全程采样、快照自动恢复读回校验）均已严格文档化；
  3. 全量原始数据（包含长尾分布）完整保存，无任何主观离群点修剪；
  4. 在基准配置、独立种子（424242）以及独立物理核心（CPU6）上均实现了稳定、高精度的复测，证明测量框架具备高度可重复性，完全满足题面 R02 的所有规定要求。

### **R04 结论：关闭**
- **理由**：
  1. 输入设计包含 5 种明确类对，每类样本量达 10,000 次，拒绝小样本判定；
  2. 全面应用均值、标准差、分位数、置信区间及统计假设检验；
  3. 事前确立包含 $m=8$ 项检验的假设检验族，经 Holm–Bonferroni 多重比较校正（FWER $\alpha=0.05$）后，未修版本的主时序差异在 CI（$p=1.30 \times 10^{-5}$）与 dudect（$p < 10^{-150}$）中均稳健拒绝原假设；已修版本均不拒绝；
  4. 正态近似 CI、RTLF 秩分位数检验（$\alpha=0.01$）与 dudect 三套独立检验工具实现 100% 交叉印证；
  5. 经过跨种子与跨核心两轮独立复测，未修版本每次置信区间均离开 0 且同向为正、dudect 均报阳性、RTLF 均报显著差异；已修版本每次置信区间均跨越 0、dudect 均未达到门限、RTLF 均无差异，彻底排除了单次偶合，完全满足题面 R04 的所有规定要求。

## 4. 科学声明边界与统一口径

按照工程规范与学术严谨性要求，本结论恪守以下科学声明边界：
1. **不做密钥恢复**：本实验仅评估解封装时间侧信道的统计可区分性，未实施也不主张对私钥的端到端恢复攻击。
2. **不可区分不等于绝对恒时证明**：修复版本在当前 10,000 样本量及纳秒分辨率下显示“maybe constant time / 未检出统计差异”，这一结果仅表明在给定实验统计功效下未拒绝零假设，在形式化或硬件微架构层面并不等同于全指令级“数学恒时证明”。
3. **环境与架构范围限定**：所有阳性与阴性结论严格限定在 `x86_64`、`Ubuntu Clang 18.1.3`、`-Os -fno-vectorize` 的 portable C `*_ref` 解封装路径，不外推至其他未测试的编译器、架构或微架构。
