# M4 统计采集合同草案（未冻结、未采数）

本草案用于主控冻结下一轮采集；本路只编译及测试 `--describe`、输入生成和参数拒绝，不执行 `--collect`。必须在具体源码、普通 ELF、采集控制器、PLAN 路径/摘要和本地提交固定后才能采样。

对象为人工相等性比较夹具，不是完整 KEM。计时边界是一次 `m4_compare_checked` 完整封装调用：两个公开长度都为 32 字节，包含封装边界检查和内部内核；输入生成、分配、类序乱序、结果检查/消费、日志、CSV 保存和 I/O 在窗口外。Linux 时钟 `CLOCK_MONOTONIC_RAW`、单位 ns；其他 ISA 只能作为软件资格。

两类公开人工输入：候选数组恒为 32 个 `0x5a`，秘密数组分别仅第 0 字节或第 31 字节异或 1，标签 `mismatch-first`、`mismatch-last`。两类输出同为不相等，不把返回值或日志分支差异当成泄漏。每次在窗口前复制全部 32 字节到同一个工作数组，使用同一个候选数组；因此是输入已触碰的同地址比较合同，不把两套固定地址差异混入类对。每相邻 pair 各含一类，SplitMix64 仅由显式测试种子决定先后；该种子不是密码随机源。

拟定主采集：每变体 100000 次/类、200000 调用/进程；三个分别启动的主进程，种子 `2026101607`、`2026101707`、`2026101807`。保留全部原值和次序，不删长尾、不因结果追加样本。三个近邻进程是同机描述性重复，不声称独立环境；正式族基于第一个预定进程，其余仅复测方向、效应和差异，不拼接放大有效独立单位。

拟定参数族 `M4_artificial_compare_first_session_v1`，成员仅 vulnerable 与 ct 各一个双侧类均值差检验，m=2、FWER α=.05，CI/Welch 由当前平台统计实现给出（正态近似口径，不称精确 Student t），主族 Holm 单独生成。时序依赖/平稳性及独立采样前提须另审；未认证这些前提时仅给条件性统计与同机描述，不将名义 FWER 写成真实总体保证。RTLF α=.01 单独交叉，使用完整主 CSV；不作为此 Holm 的成员。dudect 无有效 p，不进入 Holm。

拟定在线 dudect：独立普通 ELF，每批 20000 调用、固定 10 批、每变体一个预定进程，显式种子 `2026101907`。调用原上游 `dudect_main`，真实 MFENCE/RDTSC 与原统计内核；固定预算内即使提前报泄漏也继续到预算，保留原日志。首批被上游用于预热/百分位；每批 20000 次调用形成 19999 个相邻 tick 区间，保留原 ticks、类标签和全部区间，明确每次统计更新丢弃首 10 和末端 1 个样本及原有裁剪/高阶检验。这个时钟窗口含上游计时/循环/回调边界，单列为工具交叉，不与 ns CSV 混合。

普通采集与在线 dudect 均由主控串行锁频合同运行：boost 关、目标 policy performance、约 4300000 kHz、taskset CPU2 或 CPU6、进出 `restore_match` 核对，退出必恢复。采集工具不自行写频率/隔离，也不伪称外部合同已达成。若配置、计时或结果检查失败，保全已完成原值并标失败，不替换正式样本。
