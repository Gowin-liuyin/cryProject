## 作为题面第 9 条增量的口径

- **增量内容**：三台队友机器在 **WSL2（未锁频、虚拟化、绑 vCPU 而非物理核）** 上重跑本平台关键实验，
  与主平台的**裸金属锁频**环境形成「跨运行环境对比」。
- **确定性证据逐项一致**：三台 × 12 个臂的秘密标记 Memcheck 命中上下文数与主平台完全相同
  （未修 `-Os` 1、`-O2` 8、`-O3` 15、`-O0` 0；已修四级全 0；M5 四级全 0），反汇编形态亦逐项相同。
- **时间证据只作方向性对照**：WSL 单次 SE 约数百 ns，掩盖了主平台 25–40 ns 量级的效应；
  这是**测量下限**差异，不是结论分歧。
- **不改写主平台判定**：WSL 结果**不进任何 Holm 家族**、不与裸金属数据合并、不作恒时证明，
  也不给出总体误报率。
