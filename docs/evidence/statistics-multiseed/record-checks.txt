== 7. 目录级 SHA256SUMS 的生成与核对 ==
# 生成命令（在仓库根目录；路径为仓库相对路径，与既有证据目录同口径；不含自身）：
$ find docs/evidence/statistics-multiseed -type f ! -name SHA256SUMS \
    | LC_ALL=C sort | xargs shasum -a 256 > docs/evidence/statistics-multiseed/SHA256SUMS
# 核对命令与预期：
$ shasum -a 256 -c docs/evidence/statistics-multiseed/SHA256SUMS
