# G2 原始频率窗口的独立科学核对

2026-10-10。仅复核已经取得的原始文件与固定 C11 分析输出；未连接远端、重跑负载、
执行密码操作或修改原件。本审查不替代另行保存的进程、分区、调频恢复与来源绑定审查。

## 结论与适用范围

**本次完成进程的窗口分析有界通过，未发现阻断缺陷。** 固定 C 分析器的工程诊断
`yes` 与原始整数记录一致：CPU2 的全部 200 个实际主阶段 pair 均满足预定读跨度、
采样间隔、活动代理与条件读取对齐入带规则，包含首个跨主阶段起点的 pair。
这支持“本次单进程中，全部观测 CPU2 窗口通过既定工程规则”的窄声明。

200 个 pair 来自 **一个完成进程**，不是 200 次独立重复。八份普通有效密文依次循环，
不是 iid 样本设计。本次没有计算置信区间、错误率或检出率，也不能推出瞬时物理频率、
每次短调用的频率界、整段主阶段恒频、秘密无关性或恒时证明。
`full_main_coverage_certified`、`physical_precision_certified`、R02 与 R04 均保持 false。

## 输入与方法

核对对象为 schema 1 普通参考生产者的
[`originals/normal/worker.stdout.jsonl`](originals/normal/worker.stdout.jsonl)、
[`analysis/normal-windows.csv`](analysis/normal-windows.csv) 与
[`analysis/normal-summary.json`](analysis/normal-summary.json)。固定 C 分析源 SHA-256 为
`5c028abf419df5b5459c167469f44724faba12542b446799c5c5fc6b02d5a9f4`。

| 文件 | SHA-256 |
|---|---|
| 原始 JSONL | `c29a9ca0e28ffad53aaeb0e0c0097fd560d048f5eee4803885cb56850a989028` |
| 逐窗口 CSV | `9927e729dc3ccb64d8dbf658eea396d9e5258c80aecdf20b243395991a948a06` |
| C 摘要 | `6f37ab32330c267898b6ff7e9f5ad2b326e9a0ecdde4164a50e69454dda4f518` |

独立核对使用 Python 任意精度整数与有理数作为交叉检查，不替代 C 的正式分析输出，
不产生新统计方法。对全部原始记录重建调用、检查点和快照的实际时间顺序，逐项核对
返回状态、原 elapsed_ns、阶段边界、64 次调用检查周期、20 ms 调度期限与未漏过期限。
再从原始 E7/E8/E7 计数独立重算两 CPU 的全部 400 行窗口，与 CSV 的整数列及分类核对。
没有删除或筛选窗口、长尾与失败记录。

每个 pair 使用 `L=M_next_minus-M_previous_plus`、
`H=M_next_plus-M_previous_minus` 和 `delta_A=A_next-A_previous`。
条件读取对齐区间为 `[4300*delta_A/H, 4300*delta_A/L] MHz`，4300 是既有固件标尺；
单调、同一计数时期与无重置的条件不能由解析成功单独证明。
全部 CPU2 pair 的 `L>0`，且使用精确整数判定
`100*delta_A >= 99*H`、`100*delta_A <= 101*L`；所有实际乘积也在 uint64 范围内。
浮点显示列不参与本次通过判定。

终点为有效 end 快照的 `raw_after`。首个 pair 的平均含有主阶段起点前成分，

## 父进程丢失路径与结果到声明

父进程丢失路径的原始 stdout 为 0 字节；其 C 分析退出失败，CSV 为 0 字节，摘要明确
`missing_summary_or_count_mismatch` 与 `engineering_diagnostic=no`。这符合缓存尚未输出
便被终止的记录边界；它表示测量证据缺失，**不表示执行了零次密码操作**。
该路径的恢复成功与否应读管理原件，不能用空测量文件替代管理审查。

结果到声明建议：窄工程窗口观察可记 `claim_supported=yes`；完整受控测量与研究总目标
仍为 `partial`，R02/R04 不升级。后续补充须按预先固定的测量与统计合同推进；
不能把本次 200 个相邻窗口当作独立重复来增加样本量，也不能把 ±1% 工程频率带
改称安全差异阈值。来源真实性、物理计量、真正独立重复与适用统计前提各需相应证据。
