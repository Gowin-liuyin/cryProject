# WSL 跨环境复现与主平台一致性核对（2026-10-20）

对象：三台队友机器的 WSL2 复现实验包（`docs/evidence/wsl-repro-20261020/`）与主平台
（裸金属 x86_64 Linux，仓库证据目录 `docs/evidence/r09-optlevel-20261016/` 等）。

**核对原则**：确定性证据（秘密标记 Memcheck 命中上下文数、产物分支形态）逐项比对，
这三项不依赖机器速度，应当一致；时间证据（合并 Δ 与 CI）只作方向性对照——WSL 是
**未锁频虚拟化**环境，采样噪声量级与裸金属锁频环境不同，把两者合并或要求同号都是错误的。
**WSL 结果不进主平台的任何 Holm 家族，也不改变主平台既有判定。**
