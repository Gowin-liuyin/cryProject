## 复现方式

三台机器的复现依据是仓库内 `docs/wsl-repro/` 的执行文档与 `wsl_repro.sh`（基线提交 `04baad4`）。
各包内的 `out/RESULT.md` 是该机器自己写的复现报告，`out/stats/SUMMARY.md` 是逐次统计与按臂合并表。

一致性核对由 `scripts/check_wsl_repro_crosscheck.py` 生成，可重跑：

```sh
python3 scripts/check_wsl_repro_crosscheck.py
```

退出码 0 表示确定性证据逐项一致；非 0 表示存在不一致项并逐条列出。

## 核对结论摘要

- **确定性证据逐项一致**：三台机器 × 12 个臂的秘密标记 Memcheck 命中上下文数与主平台完全相同
  （未修 `-Os` 1、`-O2` 8、`-O3` 15、`-O0` 0；已修四级全 0；M5 四级全 0）。
- **时间证据只作方向性对照**：WSL 是**未锁频虚拟化**环境，单次 SE 约数百 ns，掩盖了主平台
  25–40 ns 量级的效应，三台机器的 M1 未修 `-Os` 合并区间均含 0。按执行文档第 9.2 节的预期登记，
  **不改写主平台判定**。
- **M4 是人工构造校准**：三台机器的 vulnerable 臂合并区间均不含 0（−7.13 / −11.97 / −22.37 ns），
  说明采数管线在有真实效应时能检出；M4 不外推为真实库攻击结论。
- **未覆盖面**：三台机器均未锁频、无 cpufreq、绑 vCPU 而非物理核、未装 R/tidyverse（RTLF 不可用）、
  未执行网络路径；不构成恒时证明，不给出总体误报率。

## 归档纪律

- 包内 `out/` 是队友机器上的原始产物，本仓库**不改写其中任何字节**；摘录与核对只发生在
  `CROSSCHECK.md` 这一层。
- 三个原始 tar.gz 的 SHA-256 记录在 `MANIFEST.sha256`，原始包本身不在仓库内（体积约 6.6 MB，

- 这些结果**不进主平台的任何 Holm 家族**，不与裸金属数据合并，不改变 M1–M5 的既有判定。
