# M4 人工比较夹具：本轮软件准备计划

2026-10-16；本轮只进行源码、构建和功能自检，不采集时间样本，不更改频率或 CPU 隔离。

- 对象：自有 32 字节相等性比较。vulnerable 逐字节比较后提前退出；ct 对全部公开长度字节异或归约。两者仅返回相等/不等，不提供 memcmp 的排序语义。
- 性质：**人工构造，用于校准**，不属于真实 CVE，也不是 KEM 解封装实现；不接入或修改 M1。
- 功能资格：两变体分别对照标准库 `memcmp(...) == 0`；枚举 0–32 字节长度、每个差异位置、全部 256 个替换字节。封装层拒绝空指针及非 32 字节长度，使用真实短数组检查边界。
- 构建：独立 CMake/CTest；普通与 ASan/UBSan 分目录。macOS/ARM 结果只作软件资格，不冒充 x86_64 Linux 证据。
- 定位准备：可选 Valgrind Memcheck poison hook；正式运行需固定 Linux 二进制和工具版本，并分别保存日志。输出消费前取消 poison，不把夹具返回值导致的消费者分支误记为比较函数泄漏。
- Binsec 目标：抽出的比较内核，秘密数组 16 字节，候选数组及长度公开，`1 <= length <= 16`；入口 `main`，终点 `exit`；深度 10000，超时 120 秒。只在完整探索并得到工具结果后报告该边界下的 secure/insecure；未运行、超时、缺依赖均写 unknown/not_run。
- 后续统计：先由主控冻结独立正式 PLAN 并提交，再采数；候选类为首字节不同与末字节不同（两类均不等，避免比较结果差异）。不得把 dudect 最大 t 伪作 p 值加入 Holm。
- 后续采数环境：仅主控调度的单任务使用 CPU2/CPU6；boost 关、performance、约 4.30 GHz、taskset、进出 `restore_match`，异常退出也恢复。远端文件与缓存只能位于 `/home/nss-marker/yhr/Cry` 的物理子树。

禁止密钥恢复、exploit demo、改写既有证据、修改只读 vendor、自动 push。此计划不宣称任何统计阳性或恒时证明。
