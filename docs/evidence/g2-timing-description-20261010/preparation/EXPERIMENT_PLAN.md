## 固定计算

核心处理、数值与运行校验用C11，复用既有严格JSON解析、完整性、阶段及调度校验；不另建通用解析或统计平台。旧 `analyze_windows INPUT.jsonl` 的CSV和JSON须逐字保持，新 `--timing-description INPUT.jsonl` 使用独立输出路径。旧dd67390/5c028a源、旧结果、49页报告和925项包不改写成本次版本。

仅在完整成功、全部调用/时钟有效、无序列异常和终止快照完整时输出。无效调用、缺失或失败不得删除后汇总。预热与主阶段分别给全体及input0—7，18行；主阶段按原调用顺序的四个连续段，边界为 `floor(q*N/4)` 至 `floor((q+1)*N/4)`，每段给全体及input0—7，36行。实际主阶段每段25312次、每输入3164次，不将四段或八输入当独立实验。

每行给数量、uint64精确总耗时、均值显示、最小值、P50/P90/P99、最大值及MAD，单位ns。均值的权威值为整数总和除以数量，12位小数只供显示。分位数沿用现有inspect_timing的最近零基索引 `floor(p*(N-1)+0.5)`，无插值；用整数分数计算索引。MAD以相同P50规则取得的中位数为中心，计算绝对偏差，再按相同规则取P50。保留全部普通长尾，不扣读钟开销。
