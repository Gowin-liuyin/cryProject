## Nice to have

1. **收紧输出失败的退出码表述**（`docs/research/aris-g2-timing-description-20261010/README.md`第二段）。
   - **What this is:** README称“输出写入错误也返回1”。主入口确实在stdio可观察的写入/刷新错误时返回1。
   - **Problem:** 向已关闭的消费管道写出时，进程默认可因SIGPIPE终止，未必有机会执行返回1。这是具体的文案边界，非本次文件重定向执行的源码阻断。
   - **Fix:** 将该句改成“检测到输出写入/刷新错误返回1；管道信号等异常终止均按失败处理”。不必加入新信号处理或改旧模式行为。
   - **If we skip it:** 下游若把“只有退出码1才是输出失败”当成契约，会漏识别信号终止；当前合同要求核对成功退出0，正常文件输出执行并不依赖此误解。
