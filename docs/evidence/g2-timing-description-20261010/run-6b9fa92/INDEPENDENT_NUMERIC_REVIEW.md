分位秩用Fraction表示`p*(N-1)+1/2`并取整数下取整，再访问排序原值；MAD由这个上中位数的全部绝对偏差按同一秩取得。它未调用主C的排序、分位或MAD函数。均值权威值为精确整数sum/count。12位显示允许binary64半ULP加十进制格式化半个`10^-12 ns`的表示误差；最大实际差为`1563/395500000000000 ns`，约`3.952×10^-12 ns`，小于此界。此界仅是数字显示舍入，不是物理测量误差或精度声明。
