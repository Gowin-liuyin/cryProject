## 4. 分层结论（三句话模板）

1. **定位**：未修链 `pqcrystals_kyber768_ref_poly_tomsg` 含 1 个 `div`，已修链 0 个；
   KyberSlash varlat 在未修 1280 errors / 3 contexts、已修 0/0。**定位层阳性。**
2. **统计**：完整解封装家族（m=6）拒绝 0；只包该除法热点的微基准家族（m=6）**同样拒绝 0**
   （合并 Δ=+0.044 ns，CI 含 0）。**两层端到端与热点层在本机都未检出可归因的时序差异。**
3. **边界**：`div` 机制只在普通 `-Oz` 构建成立，本轮采集件锁定该摘要；
   微基准窗口只包一个热点函数，与完整解封装**不可比**，两族 p 值不合并；
   "未检出"不是恒时证明。本层不改变端到端家族的 Holm 判定，也不用定位层阳性替代统计阳性。

## 5. 登记但不影响本层结论的机制事实

已修臂 `poly_tomsg` 在 `poly_reduce` 之后仍可达的系数值 −2497 上与未修臂输出不一致
（未修 bit=0、已修 bit=1，见远端 `disasm/NOTE-poly_tomsg-minus2497.txt`）。
本微基准的两类输入（各 256 个系数）都不含该值，两臂输出逐字节相同，
因此不影响本层结论；该观察只登记为固定产物上的机制事实。
