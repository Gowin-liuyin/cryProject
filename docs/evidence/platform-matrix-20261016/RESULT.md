- M1 仅引用已有封存证据，不改 `vendor/liboqs-0.10.0/`、`liboqs010-*`、
  `tooling-strengthen-*`、`r02-r04-*` 结论；本页不重新签收 M1。

- CPU2/CPU6 采数由主控串行调度，退出必恢复并核对 `restore_match`；不自动 push。
