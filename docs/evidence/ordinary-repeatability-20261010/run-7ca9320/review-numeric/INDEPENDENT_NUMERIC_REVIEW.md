实际两批原件的独立复核通过，差异清单为空。未参与collector/analyzer实现的复核者仅以Python标准库、整数、Fraction、独立排序与上中位数计算进行一次性外部算术对照；产品统计入口仍为冻结C程序。本任务没有调用产品C、collector、SSH或新采样。

原始十八字段逐项检查了index/phase、两读尝试及timespec、errno、秒纳秒转换与uint64范围、非降原序及差分、完整操作是否执行/状态/公开fixture匹配。每阶段三个序列独立重算，分位位置固定为floor(P×(n−1)/100+1/2)，MAD为相对上中位数的绝对偏差的上中位数；未用浮点数、插值分位数、池化、p值或置信区间。
