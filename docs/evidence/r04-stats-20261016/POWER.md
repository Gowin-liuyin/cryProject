## 1. 方法

### 1.1 数据粒度

一行 = 一个**主类对实例** = 一次 run × 一个臂 × 两类样本（class0 − class1）。
这个粒度与预注册 Holm 家族的成员表 `stats/members/members.csv.gz` 完全同构，
所以家族 m 可以直接套用（M2 = 3 run × 2 臂 = 6，M3 = 6，M4 = 6，M5 = 3）。

- **主类对**：M1 未修/已修、M2 未修/已修、M3 on/off、M4 vulnerable/ct、M5 reference。
- **R03 两个族外对照**：对照 A `valid vs malformed`、对照 B `valid vs truncated`，各 3 臂 × 3 种子。
- 平台侧各模块的**对照类对**（M2 malformed-zero-tail/ff-tail、M3/M5 bit-flipped/random、
  M4 截断对照）不在本页范围内：它们不是主类对，也不是 R03 的两个对照。

### 1.2 每类 SD 与 n

SD 一律取**样本标准差**（`numpy.std(..., ddof=1)`）。
口径由既有证据锁定：`stats/members/members.csv.gz` 的 `sd0_ns`/`sd1_ns` 与各
`stats/<dataset>/ci_welch.json` 的 `standard_error_ns` 都能被 ddof=1 逐位复现，ddof=0 不能。
本批全部 41 个主类对都是 `n0 = n1 = 10000`（预热 100 次在计时窗口外，不计入）。

### 1.3 MDE 公式与实现

两样本、双侧 α、目标功效 1−β、等 n 的最小可检测效应：

```
MDE = (z_{1-α/2} + z_{1-β}) * sqrt( sd0^2 / n0 + sd1^2 / n1 )
```

本页取 α = 0.05、1−β = 0.80，于是
z_{1-α/2} = 1.959963985、z_{1-β} = 0.841621234，两者之和 = 2.801585218。
等 n 时它退化为教科书的 `2.8016 * sd * sqrt(2/n)`；实现保留不等 n 的一般形式。

实现：`robustness-src/r04_common.py::mde_ns`，正态分位用标准库 `statistics.NormalDist().inv_cdf`，
不引入近似表。MDE 是**统计可检测性**（在给定 n 与实测离散度下，80% 功效能分辨的最小均值差），
不是物理泄漏阈值、不是密钥恢复门槛。

### 1.4 Holm 校正后的有效 α

Holm 逐步法的最小阈值是 `α/m`（最显著那一项）。要在**整族**上保证设计期功效，
就要按最严阈值反推可检测效应，因此本页取

```
α_eff = α / m        （族外不校正：α_eff = α）
```

家族与 m 直接取自已提交的预注册成员表：M2 = 6、M5 = 3、M3 = 6、M4 = 6、**M1 = 6**。
R03 两个对照没有预注册家族（R03 PLAN 写明「不做 Holm、不做任何多重比较校正」），故 α_eff = 0.05。

## 2. 一句话结论（可直接引用）

> **M2/M3/M5「端到端未检出」的确切含义是：在本机、本编译产物、本类对与本次样本预算下，
> 观测到的类间均值差小于本设计的最小可检测效应 MDE（M2 约 25–67 ns、M3 约 18–34 ns、
> M5 约 14–28 ns），所以这套预算**分辨不出**任何小于该量级的效应；
> 「未检出」= 观测效应 < MDE，**不等于零效应**，也不构成恒时证明或物理泄漏界。**

可检测性上界不是一个「泄漏界」：MDE 说的是「用这套 n 与实测 SD，80% 功效能分辨多大的均值差」，
不是「机制最多只能泄漏多少纳秒」。

## 5. 用 MDE 读「未检出」

### 5.1 数值读法

- **M2**（家族 m = 6，α_eff = 0.008333）：主类对 6 项的 |Δ| 全部小于 Holm 有效 α 下的 MDE
  （MDE(α) 19.9–54.0 ns，MDE(Holm) 24.7–67.1 ns），所以预注册家族 Holm 全部不拒绝。
  这套预算对**小于几十纳秒**的端到端均值差没有分辨力。M2 的**定位层**阳性的内容是
  「未修链三个热点各含 1 个 `div`、已修链 0 个」，那是**指令与数据流层面**的结论，
  不是本机测到的物理时差；两层互不冒充（见 `m2-kem-20261016/RESULT.md`）。
- **M3**（m = 6，MDE(α) 14.2–27.1 ns，MDE(Holm) 17.7–33.7 ns）：on / off 两臂的 |Δ| 都小于 MDE，
  属于「观测效应被预算盖住」。M3 是**人工构造校准**，本页只记录可检测性，不据此作泄漏结论。
- **M4**（m = 6）：vulnerable 臂的 |Δ| **远大于** MDE（3/3 run 超过，最坏情况下 MDE(Holm) 也只有 1.47 ns，
  而 |Δ| ≈ 3.5–4.4 ns）；ct 臂的 |Δ| 小于 MDE（0/3 超过）。
  这正是「该臂的效应大到这套预算足以分辨」与「该臂分辨不了」的分界。
  注意 M4 是**人工构造校准**（人工提前退出比较夹具），不是上游 CVE。
- **M5**（m = 3，MDE(α) 11.7–24.5 ns，MDE(Holm) 13.5–28.3 ns）：|Δ| 小于 MDE，未检出。
- **M1 未修**：Δ = +39.337 ns，|Δ| **超过** α = 0.05 下的 MDE 25.271 ns。
- **M1 已修**：Δ = -13.209 ns，|Δ| **小于** MDE 28.629 ns。
  这两个数**属于 M1 预注册的 m=6 家族**（见 §1 更正），按 α_eff=0.05/6 计算；
  （`tooling-strengthen-20261015/PROTOCOL.md` 里那句「没有 Holm」只描述该轮 CI 路线自身的口径，
  已被 `r02-r04-close-20261016/PLAN.md` 预注册的 m=6 家族与冻结的 `holm.csv` 取代。）本文件的 MDE 是事后功效描述，不改变 `r02-r04-close-20261016/holm.csv` 里已冻结的判定。同一批数据的族外 online dudect
  方向相同（未修臂三次越过上游 `t > 10` 阈值、已修臂三次都在 2.05 以下），同样不进 Holm。
- **R03 对照 A**（valid vs malformed）：9 个「臂 × 种子」组合的 |Δ| 都小于 MDE（0/9 超过），
  即隐式拒绝路径与接受路径在本预算下不可区分；**对照 B**（valid vs truncated）的 |Δ| ≈ 29–55 µs，
  比该对比的 MDE（约 7–21 ns）大 3–4 个数量级，说明这是封装层长度检查的接口语义差，
  不是秘密相关泄漏。两者都**族外**（R03 PLAN：不做 Holm、不做任何多重比较校正）。

### 5.2 「未检出」的正确措辞

未检出 = 「观测效应 < MDE」。它**不**推出下列任何一条：

1. 效应恰好为零；
2. 机制在物理上恒时；
3. 攻击者不可利用；
4. 换机器、换编译产物、换类对、换样本预算后仍然未检出。

它**确实**推出：在这套 n 与实测 SD 下，凡是小于表中 MDE 的均值差都照不出来；
要缩小 MDE，只能按 `MDE ∝ 1/sqrt(n)` 加样本，或降低测量噪声（锁频、绑核、缩短窗口）。

## 6. 边界

- MDE 是**统计可检测性**，不是物理泄漏阈值，也不是恒时证明；本页不给出物理误差界。
- 本页**不做密钥恢复**，不运行 exploit demo，不给出真实总体检出率/误报率。
- MDE 用的是**本次实测 SD**，属于事后（post hoc）功效描述：它说明「这套数据能看见多大」，
  不是事先的样本量规划，也不改变任何已提交的 Holm 判定。
- M3/M4 是**人工构造校准**（M3 为 LUT 机制校准、M4 为人工提前退出比较夹具），不是上游 CVE。
- R03 与 dudect/RTLF 一律**族外**；dudect 的最大 t 不转伪 p，本页不引用它做任何 MDE 计算。
- M1 的实测样本取自 `liboqs010-locked-20261015/runs/{vulnerable,fixed}/samples.csv`
  （锁频采集，单次、seed 31337、CPU2），与平台四模块的控制器采集不是同一条流水线；
  `tooling-strengthen-20261015/csv/*-message-zero-ones.csv` 是同一批样本的派生两列文件，
  只用于逐值一致性旁证（附录 B）。两边的 `.meta` 都有
  `cpu_affinity=not_pinned` 与 `frequency_control=not_configured` 的固定字符串，
  真正的绑核与频率门在各自 README / `logs/status.log` / 控制器落盘件里。
- 本页只读已有证据，没有新增任何采集，没有改任何已有证据文件。
