# RAW固定工具单次远端管理准备

本目录保存最终runner、行政合同、原拒绝评语及独立最终复核。三项执行前状态问题分别修复：启动计数限timeout管理进程；C分析与管理接受前不清除未知；leader/自有组未确认退出时不生成冻结manifest或tar，保留PID/PGID供核查。HOME保留原值，临时缓存指向Cry；256MiB为阶段边界预算，非硬配额，单文件RLIMIT另列。

最后新增run-claim只记录实际管理PID/tick与启动事件，不能以文件存在宣布存活，更不是collector启动或采集成功。源、预算及采样数不因此改变。纯内存selfcheck通过，独立代码审查范围通过；没有运行真实Linux流程、SSH或采集，也没有验证任何资源恢复/测时精度。实际执行另留证，R02/R04仍partial。
