# 七项能力执行台账

日期：2026-10-11。完整规格见[实施计划](EXPERIMENT_PLAN.md)。本轮只完成规划；下列实际实验均未启动。一个逻辑任务可以对应多个不可覆盖的run_id；每个run_id必须绑定源码、构建、输入、机器、协议、原件和退出状态。

状态分开填写：软件 / 实际实验 / 主张 / 作品验收。`待执行`不等于失败；`实验完成但主张不成立`必须原样保留。不得凭计划或软件自检勾选实验完成。
