# 弱均值区间的有限样本依据补充

本补充把原W3的渐近条件推进为一个显式、可能无信息的有限样本覆盖下界。保持原登记平均效应、原学生化闭区间和异质单位，不改用已知方差区间、不截断耗时，也不把弱均值换成尖锐零假设。

[完整证明](PROOF_PACKAGE.md)由方差恒等式精确移项、负向扰动尾界及独立非同分布Berry–Esseen界组成。对所有异质程度同时有效的版本，只需在理论上给定单位数、临界值和潜在方差主导比例的可信上界；后者通常不能由一次观测识别。未知主导比例时，本页保守界为零，不能据此签收真实运行。

[来源核查](REFERENCES.md)核实Tyurin固定v1的式(1)与定理7，使用其允许的保守常数1，区分一般独立与iid；未核实的另一篇0.56常数不作为依据。两名本地代理分别完成推导与[独立数学复核](../../evidence/weak-mean-finite-20261010/README.md)，包含离散闭端点、零方差、未知反事实及边界情形，不冒称同行评审或方法首创。

在本页采用的界中，4—20单位能得到的保证本身最高不足0.56；这是对这一较松下界的限制，绝不是实际覆盖率上界。95%覆盖单看本界的BE惩罚至少需要1600单位，但它只是必要条件，远非充分样本量，更不是新的运行次数建议。增加临界值、改方法或扩大单位数都须另审合同。

本模块完成终点是有限界、完整证明、来源与独立审查，没有执行枚举、模拟、C实验或SSH。原弱均值证明、协议、49页报告和925项包不改。R02/R04仍partial；接下来可针对明确的数学预算或有限代数夹具核对，但现实无携带/干扰、主导比例与适用测量条件仍须新证据。
