# 均值推断补充件的限定装配工具

本模块只生成47页报告与W1—W4研究材料的匿名静态阅读件，不运行密码、统计实验或资源管理。输入为固定327e历史包、已审47页报告和本仓库科学笔记；旧870项嵌于明确历史子根，不改旧包。

build_package.py在本机build/aris-weak-package-20261010下的新payload目录装配；mathml.py仅把固定TeX转成原生MathML；verify_package.py从最终ZIP独立重算旧成员、清单、报告、公式来源/位置、协议白名单视图及阅读与身份范围。三者属于作者/装配工具，不在匿名ZIP中分发。

数学转换只使用bundled Python及经官方wheel摘要核验的latex2mathml3.78.1任务副本。旧f0c4遗漏科学尾句的候选被加强验证拒绝；最终ec076 ZIP及实际原件见[闭包记录](../../evidence/aris-weak-package-20261010/README.md)。工具通过不签收R02/R04、浏览器像素或完整竞赛要求。
