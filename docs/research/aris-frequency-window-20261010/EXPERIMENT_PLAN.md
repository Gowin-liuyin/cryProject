## 固定来源与前置门槛

- C11 候选源固定为 `c0e5990bd4d764fbb08ff6857a2cf6cf21c9b8a2`，只链接原参考内核。
  `PR_SET_DUMPABLE=0` 在 C 入口、秘密生成前设置及回读；外部子进程设置 core 为零、
  忽略 SIGXFSZ 并限制单个输出文件大小。进程入口以前的动态加载器不在此保护范围内。
- 新管理入口沿用同一 guard、同一 `partition-admin.lock`、冻结源码、root 私有 Store、
  namespace 与路径身份门槛。固定普通 Linux ELF 的路径及摘要必须在首个资源写入前核对；
  不接受任意命令，不使用 ASan 产物采集。管理源提交及 ELF 摘要在实际运行前登记于 tracker。
- 真实机器须再次确认 `nss-m`、Linux/x86_64、Cry 实际路径、至少 2 GiB 可用磁盘、
  root CPU0—31、隔离集合为空以及全部 32 策略和 global 基线。资源不足立即停止。
- 软件检查先行：C 的自检、公开 KAT、自身转储限制在 Linux 普通与 ASan/UBSan 构建各通过；
  管理器的既有回归和新 gated 良性替身检查通过，独立源码复核无未解决阻断项。

## 仅两条实际路径

1. **normal**：guard 仅向 policy2/18 的四个 min/max 请求 4300000 kHz，并取得 CPU2/18
   临时分区。唯一工作进程在 gate 前进入 probe、亲和性为 CPU2；observer 打开其 pidfd
   后发送 W。guard 观察到受保护 ELF 的 inode/device 和存活状态，才登记 running。
   observer 等待实际 waitpid 回收及输出结果，再发送 R；恢复后独立核查原值。
2. **parent-loss**：在相同放行流程之后，observer 等待至少 0.25 秒，重新核对工作进程的
   pidfd、启动 ticks、probe 归属和 CPU2 亲和性，再仅 SIGKILL 自己的 controller。
   guard 收到 EOF 后再次判断 child 是否还活着；只有实际运行中取消、SIGKILL 并 waitpid
   回收才算覆盖此故障路径。自然退出竞态不冒充成功，也不补跑。该路径可没有缓冲输出，
   不从空文件重建调用数或测量结果。

每路径最多一次，顺序执行。前一路径未确认 guard 终止、工作进程回收及可见配置恢复，
不得启动下一路径。准入拒绝、异常、负结果及部分输出均保留，不依据频率结果追加或筛选运行。

## 生命周期、存储与恢复预算

C 固定 1 秒预热、4 秒主观察、6 秒采集软预算；250000 次完整调用、512 快照、3907
检查点，细节见 [README](README.md)。guard 的运行总软预算 20 秒，child 放行后包含输出
的预算至多 12 秒；取消后先关闭 gate、终止并回收自己的 child、核实 probe 空，再恢复
频率和分区。恢复有独立 6 秒软预算；内核阻塞不享硬实时保证。

每个 child 的 stdout、stderr 各至多 120 MiB，case 共 256 MiB；另计两个 case、源码、
软件检查、导出副本的新增磁盘预算 1.5 GiB。可读归档与 root 原件均只在
`/home/nss-marker/yhr/Cry` 下新建。不得通过符号链接越界，不改已有证据。

磁盘不足不应阻止回收 child。频率首次写入前保存原值恢复授权；仅在恢复原值、身份和
已知状态均核对通过，且新增日志因 ENOSPC/EDQUOT 失败时，允许无需新日志分配的尽力
原值重发。此时证据不完整，不能报告完整成功。其他错误、未知状态和 apply 不享此例外。
guard 自身被杀、整机故障或未知管理员冲突仍需受约束人工恢复，不声称自动恢复保证。

## 预先冻结的分析口径

由独立 C11 程序直接读取原始 JSONL，完整验证 producer 协议并输出逐窗口 CSV 和摘要。
所有主观察相交窗口，包括首个跨边界窗口，均保留并分类；不筛除长尾或坏窗口。
读取对齐区间沿用 G1 计划的 L/H 公式和 4300 MHz 标尺；区间不是置信区间或完整误差界。
工程带固定 4257—4343 MHz；CPU2 保守线程 CPU/RAW 活动代理至少 80%，三读跨度至多
1 ms，相邻快照至多 40 ms。CPU18 仅作为上下文，不强制高活动代理。

首个跨预热窗口不能算作纯主观察频率证据。纯主观察覆盖使用 APERF 读括号保守几何，
单独报告边界、括号及尾部缺口；无实际窗口不准空集通过。即使所有观测窗口通过，
`full_main_coverage_certified`、R02 总体及 R04 仍为 false；不得推广到每次短调用恒频、
真实密文总体、完整物理精度或统计检验有效性。

结果按 ARIS result-to-claim 登记支持范围、缺口及下一步；外部 Codex MCP 不可用时明确
标注待该复核，以本地独立代理审查继续推进，不伪称跨模型审查已完成。
