# 普通参考完整调用的运行间研究

本模块补充同一公开有效输入下完整ML-KEM-768参考调用的新进程观察。固定两次近邻连接执行批次、每批三个新进程，每进程25000次预热和25000次主调用；分别保存原值、C描述和整数时间账，避免把逐调用读数当独立重复。见[实验合同](EXPERIMENT_PLAN.md)及[实际执行表](EXPERIMENT_TRACKER.md)。[本机软件资格](SOFTWARE_NOTES.md)普通/动态各4/4和独立审查已通过，Linux资格和正式采集仍未执行。

[两批管理准备](REMOTE_NOTES.md)已完成源/产物/预算/归属及原件终检设计、独立审查和纯自检；142成员候选载体已核对，仍需绑定实际部署提交后运行。不以计划、旧控制连接或候选包当作已启动实验。

输入是固定NIST ACVP `tgId=5,tcId=86`，公开dk/c/k的字节与原JSON、转换向量一致，独立预期答案不由本程序产生。派生头只用于明确测试场景，不承载真实业务秘密。程序只链接原普通reference，不修改密码核心或上游，不运行缺陷变体、秘密类别比较或漏洞复现。

完整封装调用位于两次RAW原始读钟之间，转换/检查、全输出对照/消费和擦除在后读之后。C入口只设置自身CPU2亲和性并禁止进程转储，普通与动态构建分离，正式仅普通产物。新元数据和十八列CSV明确算法是否执行、返回状态及公开fixture完整性，失败/未知/普通长尾保留。静态数组、固定次数和参数均随源冻结，不建立通用计时或统计平台。

六个新PID、两次连接或接近的分位数都不自动证明iid、独立环境、长期稳定或目标差异可检测。完整调用窗口不扣除旧RAW的20ns空窗；声明分辨率、经验分布及物理精度分开。R02/R04尚未因此签收，已有49页/925项交付和旧证据保持原身份。所有云端项目文件仍只允许Cry物理子目录。
