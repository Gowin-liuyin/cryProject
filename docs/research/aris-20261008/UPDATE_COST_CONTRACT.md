# 固定整数任务的同语言更新成本合同

日期：2026-10-08。本合同在新实现与正式执行前保存；Git提交身份仍待核，不称可信预注册或外部时间证明。沿ARIS消融规划，以同模型独立审查替代当前不可用的Codex MCP。

## 问题与对象

问题是：保持完整统计函数语义与编译条件时，逐状态增量和值相对逐状态完整求和是否节省固定任务成本。该比较不使用ML-KEM、不调用密码实现、不重新采集时序缺陷，也不改旧八任务、阈值或C01/C03结果。

复用八份C01确认CSV。每份20对，完整交换空间2^20。task-3与task-7原字节相同且全零；因此是八个预定任务、七种不同CSV、六份非零差向量，不能写成八种不同数据或新独立确认。

## 固定设计

| 项 | 合同 |
|---|---|
| 候选 | 固定当前生产compute_controlled_result源码，compute_interval=0 |
| 对照 | 同一源码副本仅替换逐状态和值计算及必要函数名，每个Gray状态重新求20项；校验、初始化、顺序、绝对值、含等值上尾及结果整理保持 |
| 编译 | C11、同一编译器与-O2条件、独立翻译单元、无LTO；允许自然优化/向量化，不加volatile、优化压制或空转 |
| 数据 | 运行时读取；全部八份CSV及原声明保留，输入摘要前后不变 |
| 计时 | C CLOCK_MONOTONIC，主窗口为完整统计函数入口；读取、预热、结果核对/消费与I/O在窗口外；不称纯内循环 |
| 重复 | 每任务十对执行，每对方法顺序交替；每方法五次先执行；预热每方法每任务一次，计数亦须核对 |
| 读钟 | 预先记录256个连续读钟步长及256个空窗口原值；不扣开销，算法窗口须至少达到max(标称分辨率,空窗中位值)的100倍才支持该窗口成本解释 |
| 输出 | 逐次时间、顺序、计数、输入/源/产物摘要、实际编译与链接命令、原分辨率及全部失败；管理窗口起止和排除项单列，不冒称外部完整进程墙钟 |
| 产物 | 保存两个函数反汇编；核对编译/链接无LTO及零阈值路径是否保留实际和值工作；计数相同不证明实际逐态循环存在 |
| 数值 | 每次与独立已归档SciPy计数核对；八个尾数为791138、124、1048576、811486、203246、62、1048576、470724，分母均1048576 |
| 预算 | 一次正式执行，主程序自入口读钟起30秒，包括读取、校准、预热、计算和原始记录写入；最终状态发布边界单列。软件/动态检查与正式计时分开 |

本次目标环境为本机Apple Silicon/macOS，源、构建与输出仍在仓库根目录体系内。最新普通SSH预检：KVM连接关闭，裸金属认证失败，未运行任何远端实验；不以旧预检冒称本轮连接成功。CPU兼容资源检查已确认10逻辑CPU、16GB内存及足够磁盘，GPU不需要。

## 判定与停止

计数不符、输入改变、读钟或输出失败、预算耗尽立即停止，保留部分记录；不调编译器、次数或任务直到获得好看结果。窗口太短或产物折叠时保留记录并将相应成本/逐态机制解释记证据不足，不加人工工作补时钟。

预期六份非零向量在增量入口具有较低成本；无差异或只在部分任务出现也照实报告。每任务逐次时间与对应比值、范围分别展示。十次重复属于同一产物和进程的重复执行，不是十个独立构建、机器或任务。

所得差异包含加载、符号选择、changed-bit定位等实现影响，不解释为纯加法次数比；不能定量分解原C/SciPy完整流程收益、证明普遍加速、改进检测能力或关闭R02/R04。零向量尤其不能用来证明每态更新收益。

## 实施边界

实验代码为本研究的专用C观察器及固定自有源码副本，使用独立CMake/CTest配置，不给产品CLI新增模式、不改变原六模块、vendor或旧分析器。实现前记录生产源码完整摘要；副本与朴素差分单独检查。先做小型独立手算及动态检查，再检查产物，最后只执行一次正式比较。
