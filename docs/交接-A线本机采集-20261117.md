## 3. 三层结论

产物、定位、统计分开。含 0 的 95% CI 记为未检出。未检出在这里表示这次区间含 0。

### 产物层

`secret_conditional_jumps`：A0/A1/A2 = **1/1/0**。

- A0/A1 用封存 Linux ELF。摘要与 PLAN §1 一致：`b1e820e8…6b5d`、`c9cecdafb6…e9a8`。这两份 ELF 没有在 Mac 上执行。
- A2 没有封存的全链接 ELF。门打在补丁后 `poly.c` 的 ELF 目标文件上，计数为 0，`verdict=branchless`。补丁 SHA-256 `5e7fe0fce1132f0a13e0202e4bed73f0664231a686866836fb4510cd14838eed`。
- 对可运行 Mach-O 跑同一脚本会得到 `verdict=symbol_not_found`。日志里的 `secret_conditional_jumps=0` 是符号没找到时的空计数。产物层以封存 ELF 和 ELF 目标文件为准。

上一份交接 §6 里的简写「产物 0/1/1」与冻结 PLAN 不一致。冻结 PLAN 的产物判据是 1/1/0，本趟按 PLAN 记录。

可运行镜像与封存 ELF 不是同一份文件。A1 和 A2 的 CSV 字段 `implementation` 都是 `m2-kyber768-round3-fixed`。臂别看 `run_id` 和可执行文件摘要（见包内 WRITEUP）。

### 定位层

本机没有 `valgrind`，没有安装。R0a-2 记为工具缺失。没有上下文数。反汇编没有当成 Memcheck。

### 统计层

九次主类对按冻结顺序跑完：每类 10000，预热 100，类对 `message-zero` / `message-ones`，密钥种子 31337。种子顺序是 r01=31337（A0→A2→A1）、r02=424242（A1→A2→A0）、r03=31337（A2→A0→A1）。九次都是 20000 行，`zero_elapsed_count=0`，退出码 0。每个计时值都是 1000 ns 的整数倍。

家族名 `m2_branchfix_hostlocal_unlocked_v1`，m=9，α=0.05。`platform_holm` 输出 `rejected=1`。被拒绝的成员是 `r0a-r02-a1`（A1，seed 424242），raw p = 0.000458764622472446。

A2 三个成员的 95% CI 都含 0，Holm 也没有拒绝它们，统计层对 A2 记未检出。

固定效应合并（九个成员合在一起，不是单臂结论）：58.5300665624061 ns，95% CI 从 36.2069596606786 到 80.8531734641335。这个区间不含 0，并且整个落在一个时钟刻度（1000 ns）以下。

`platform_stats` / `platform_holm` 是本机编译的 x86_64 Mach-O，不是冻结 ELF `ddc48b9e…c9e2`。
