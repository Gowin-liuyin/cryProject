## 0. 执行硬规则（每个任务开工前重读一遍）

1. **先读后写**：每个任务先读"前置阅读"列出的仓库文件，再动手。理解不了的先停下，在任务报告里写明卡点，不猜测绕过。
2. **触碰边界**：只允许新建/修改各任务"文件"小节明确列出的路径。以下目录**永远只读**：`docs/evidence/`（既有子目录）、`sources/`、`report/`、`deliverables/`、`.acl-repair/`、`acl-recovery-20261022/`、`build/`。`vendor/` 只能通过 `tools/fetch_all_vendors.sh` 重建或任务明确指定的方式获得，不手工编辑 vendor 内容（打补丁除外，且必须生成 `docs/patches/` 下的补丁文件留档）。
3. **git 纪律**：开工前 `git status` + `git branch --show-current`。若不在 `main` 或存在他人未提交改动 → **停止并报告主控**，不切分支、不 stash、不 reset。每任务完成：构建+测试通过 → format-check 通过 → `git add` 只加本任务文件 → commit（模板见附录 A）→ **不 push**。不许修改 git 身份配置。
4. **环境**：本机 Windows + Git Bash（仓库根 `D:\cryProject`）。先用原生工具链试；若缺 ninja/OpenSSL 等，改用 WSL2 Ubuntu 22.04+（路径如 `/mnt/d/cryProject`），并在任务报告里记录实际环境。禁止 `sudo` 改系统配置，禁止安装全局包（构建目录内隔离）。
5. **代码风格**（AGENTS 约定，format-check 会查）：自有函数/变量 `snake_case`，宏 `UPPER_SNAKE_CASE`；数量/长度/时间带单位后缀（`_nanoseconds`、`_bytes`、`_sample_count`）；循环索引见名知义；分支/循环必须大括号；一行一声明；注释只写必要中文（原因/边界），不逐行翻译。
6. **计时窗口纪律**：任何新采集代码，计时窗口内禁止 I/O、日志、malloc（对齐 `docs/evidence/m2-kem-20261016/COLLECTOR_CONTRACT.md` 体例）；输入生成、分配、结果消费全在窗口外。

8. **完成定义**：任务"完成判据"逐条通过 + 测试全绿 + commit 完成。缺一条就不算完成。
9. **台账**：每完成一个阶段，在 `docs/full-work-progress.md` **末尾追加**一行（日期/阶段/软件完成/留待主控项），不改写既有行。

## 3. P1 R20 形状/方差统计（离线，无硬件）

背景：现有三口径（Welch+Holm、dudect、RTLF）全是一阶固定类对均值差；题面第 4 条明文要求"方差"。本阶段补 Brown–Forsythe 方差齐性、双样本 KS、类内对半二阶对照三个检验，全部 C 实现，回放既有封存数据，不新采集。

### T1.1 `tools/platform_stats/shape_stats.c`
- **前置阅读**：`tools/platform_stats/holm.c`（CSV 解析与错误处理风格）、`scripts/platform_stats/stats_csv.c`（长表读取）、`docs/evidence/r02-r04-close-20261016/raw/cpu-6/csv/vulnerable-message-zero-ones.csv`（原始两列宽表实样：表头 `message-zero,message-ones`，每行一次成对调用）。
- **新建文件**：`tools/platform_stats/shape_stats.c`；在 `cmake/PlatformStats.cmake` 内照 `platform_holm` 段新增 `platform_shape_stats` 目标（含与该文件既有目标一致的告警旗标与 sanitizer 分支）。**注意：`tools/platform_stats/` 下没有 CMakeLists.txt，不要新建它。**
- **CLI 契约**：
  ```
  platform_shape_stats --input <csv> --format wide|long --output <out.csv> --meta <meta路径> [--label <名称>]
  ```
  退出码按附录 C 的新约定（0 成功/1 用法/2 数据；注意与 holm.c 现行行为不完全一致，holm.c 不改）。
- **输入格式**：
  - wide：首行两列类名，其后每行两列整数纳秒（允许空行跳过）。
  - long：表头 `run_id,implementation,input_category,sample_index,elapsed_nanoseconds`，按 `input_category` 分两组。
- **实现要点**（算法按此写，规则常量 `#define` 在文件头）：
  1. `brown_forsythe_statistic`：对每类 j 求 `z_ij = |x_ij - median_j|`；`W = (N-2) * Σ n_j (z̄_j − z̄)² / (1 * Σ_ij (z_ij − z̄_j)²)`（k=2）；p 值用 `F(1, N−2)` 上尾的 Beta 函数精确式或 1/(1+W) 的 Z 近似——**采用后者**（`p ≈ 2*(1 - Φ(√W))`，代码注释注明这是大样本近似、不称精确）。
  2. `ks_two_sample`：合并排序求 `D = max|F₁−F₂|`；`p_asymptotic = 2·exp(−2·n_eff·D²)`，`n_eff = n₁n₂/(n₁+n₂)`；并列值只在组号变化处更新经验分布（防并列错算）。排序用 qsort+比较函数，不引入依赖。
  3. `within_class_second_order`：每类样本按到达序对半劈（前 n/2 vs 后 n/2），做 Welch t；输出 t 与 p，`p ≈ 2*(1 − Φ(|t|))` 用 `erfc(|t|/sqrt(2))` 实现，注释注明大样本近似。用途：检出"均值同但批间漂移"。
  4. 三个检验全部写进输出 CSV：`test_name,statistic,p_value,n0,n1,verdict_exploratory`；`verdict_exploratory` 按 `p<0.05` 给 `flag`/`clear`，**列名就叫 exploratory，不进任何 Holm**。
  5. meta 文本：输入文件 SHA-256、行数、规则常量值、`family=none_exploratory_only`。
- **命名示例**：`int parse_wide_csv(FILE *input_stream, int64_t *class_zero_nanoseconds, int64_t *class_ones_nanoseconds, size_t *sample_count_out)`。
- **验证**：`cmake --build --preset baseline --target platform_shape_stats` 通过。
- **完成判据**：目标编译 0 警告（`-Wall -Wextra`）；对空文件、单列、非整数、奇数行长宽不符返回 2。
