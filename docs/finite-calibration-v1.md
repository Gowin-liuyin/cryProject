# 无秘密有限模型校准合同 v1

本补证在生成新结果前冻结，补充R04的模型内错误/检出及依赖资格验证。原两套历史分析器、
alpha及备用效率合同不改；不开展新的秘密机制采集，不作为dudect/RTLF胜负或R12新效率比较。

固定12个成对单位。噪声幅度只取两种：equal为12个1，graded依次为1..12；预定效应
delta为0、1、2、4、12。单位写作合成ns，不是实测时间。观测差为delta+s_j*w_j。
每个独立模型完整遍历4096种等概率独立符号，10个模型共40960份数据集；没有种子选择、
Monte Carlo误差或总体区间。delta=0报告有限模型误拒绝概率，delta>0报告该模型检出概率；
全零数据保留并单列，不能删除以改善检出。固定幅度不等于真实密码噪声分布。

额外两个零效应依赖模型只允许所有单位共享一个等概率符号，每个模型两种结果，共4份。
它们不满足独立交换条件：报告盲用4096交换规则的原始拒绝数，实际CLI必须返回
evidence_insufficient；拒绝签收不冒称误报降低至零。iid区间均不计算。

检验沿用abs(sum)、完整2^12交换、等值计入上尾、alpha=0.01。整数判定为tail_count*100
不大于4096。主校准计算在C中复用现有精确入口；独立核对用C整数分布逐项卷积，与Gray
状态更新分开实现，所有40964份数据的尾计数均须一致。每份数据的12个差值、标签编号、
尾计数、退化标记及原始拒绝均逐行保存，不只保留聚合结果。

外部审计使用既定SciPy1.16.3/NumPy2.3.5配置：permutation_type=samples、abs(sum)、
greater、n_resamples=inf、vectorized=True、batch=4096。每个独立模型固定审计标签编号
0、1、2047、4095（40份）；全部4份依赖数据也审计，共44份。外部工具只核对数值，不将
这些有意选定的审计行当另一次概率评价。版本、命令、报告及退出码保存，不改参数直到通过。

核验条件：所有C尾计数/分母与卷积一致，44份外部审计一致；两个独立零效应模型的误拒绝
概率不大于0.01；所有原始记录、全零及依赖状态保留。equal零效应的独立手算答案为
(2*C(12,11)+2*C(12,12))/4096=26/4096。其余效应结果不设有利的通过阈值，照实报告。
任何不一致、漏行、失败或预算不足都保留输出并判补证未完成，不删模型或调整alpha。

执行预算：C完整校准任务最多120秒（从开始任务到原始记录关闭，包括生成、卷积、精确
复算和记录I/O；最终状态写入另标边界），外部44份审计最多60秒。密码采集调用为0。
新输出目录独占；不覆盖旧确认集合、共享批次预留或此前封存文件。安装/构建/软件测试与
模型验证分时记账，不宣称任务内窗口等于全部研发成本或完整进程启动成本。

在真实授权的原生x86_64 Linux/KVM目标执行固定源码的模型验证，本地普通/动态检查仅作
软件验证。原生CPU资源及编译工具已通过aris-compute-guard核对，纯CPU小规模计算不需要GPU。
源、实际可执行文件、环境、原始行、报告和执行记录分别封存。真实密码总体校准、秘密归因、
受控防护前后与非原作者执行依然分别验收，不用本有限模型补成竞赛全部达标。
