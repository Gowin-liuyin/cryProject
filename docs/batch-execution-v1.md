## 对象、输入与数学定义

只使用未修改mlkem-native `b3ba7b32773e657dd37f6f87bce82528459ad8a4`、ML-KEM-768便携C内核。
基线仍为 `reference/benchmark` / `reference_ordinary_v1`，逐次CSV不改。
候选为同一计时源码的有限批次入口，允许K=1（软件核验）、4或16；正式候选只选4或16之一。
每次先生成三类各等量的全部输入，沿用SHAKE256/tag4拒绝采样Fisher–Yates，禁止重新分组。
有序公开输入流摘要包含规则版本、参数、公钥、数量以及每个位置的类别和密文字节，
不包含私钥、共享密钥或内部验证标志。两方法摘要必须逐字一致。

`run_mean = sum(window_total_ns)/sum(window_actual_calls)`；基线每条实际调用数为1。
短窗口保留实际次数和三类计数，不等权平均各窗口均值，不造K条单次时间。
运行级中位数：排序后奇数取中央值，偶数取两个中央值的算术平均；
MAD为各值距该中位数的绝对偏差的中位数，同样采用偶数平均。
`S=MAD(run_means)/median(run_means)`，主比值为候选S/基线S。
这一中位数定义不同于历史 `series_quantile`，不得调用旧分位数代替。

## 重采样、环境资格与中心检查

确认单位为20个完整配对运行块，每方法每块6000次、每类2000。
成对bootstrap重复10000次，每次有放回抽20个块索引，两方法共用同一索引序列。
PRNG为明确64位SplitMix64，初始状态20261029；无符号溢出按C11定义，
用拒绝采样映射到0..19，不能直接取模引入偏差。
99%区间取排序后比值的0.005/0.995分位数，采用type7线性插值：
`h=p*(10000-1)`，在floor(h)与ceil(h)间按小数部分插值。
不得删除分母退化的重采样；出现任一基线MAD=0、非有限值或中位数≤0，报告区间不可识别。

中心检查在观察数据前固定：`abs(median_candidate/median_baseline-1) <= 0.05`。
5%是用于识别批次明显改变缓存/间隔/消费节奏的保守工程筛查，不是统计等价证明。
两方法对同一原内核和输入计时；任何超过5%的中心变化阻止改进声明，即使S更小。
每方法按运行顺序报告lag1相关和前后各半均值相对变化；若绝对lag1≥0.5、
半段变化>5%、环境审查未接受，或存在无法解释的依赖，区间仅为规定模型下的探索结果。
这些筛查不证明独立；环境提供者仍须审查CPU控制、后台负载、虚拟化和运行时段。
只有经确认原生x86_64 Linux、非sanitizer、完整20对、资格均成立时才考虑支持声明。

## 成本、预算、失败与停止

子程序使用CLOCK_MONOTONIC纳秒记录准备、预热、正式采集、保存阶段及完整过程，
并生成新版本成本伴随文件；失败保留已开始记录，正常清理路径给出实际调用计数。
编排器另计从fork/exec前到wait、文件核验及记录后的墙钟，包含启动、输入生成、
分配、结果消费、全部读钟、I/O和核验。日期仅作流程标签，不参与5%成本比较。
完整比较成本包含开发/探索、预热/自检、失败、确认，以及共同编译/功能/平台准备的一半。
共同准备必须另记调用和墙钟；计数不能精确得到时给有依据的保守上界，不把未知写成0。
启动编排器前的自举构建可由调用者提供单独测量账；没有则资格为成本未闭合。
共同成本上下界均摊；成本比值使用其区间内最不利比值，不能用很大的上界人为稀释开销。

每方法200000调用上限：开发最多40000，确认120000，预热/自检/失败重试最多40000；
总墙钟上限1800000000000ns。共同调用按保守上界均摊并扣自检预算。
尝试前预留正式数+100预热；正常完成用实数结算。成本文件不完整、信号终止或失联时，
按完整预留数计入失败/自检账，不能推断为0；无法界定的外部成本使比较证据不足。
任何阶段超过预算停止；正式期间不并行编译、动态检查或其他计时。

v1不自动重试。只允许人工登记客观基础设施故障后生成新尝试清单；旧尝试原样保留、
成本全部计入，不能因结果或中心变化重跑。确认缺少20对、重复块、输入不一致、
数据截断/不完整、计数不守恒或摘要不匹配时不计算支持性结果。
余数处理为最后短窗口，记录实际K；不补重复密文，不省略最后输入。

## 选择与解释

开发仅比较两个预定K。候选须满足数据/预算完整、中心≤5%、无强依赖筛查失败且S可识别。
在合格候选中先选S比值较小者；精确并列选K4。若两者都不合格，停止路线，保留负结果。
选择只是开发结果，不作为确认；之后另提交候选和20对确认清单。
确认支持要求99%上端点严格<0.8、完整成本最不利增幅≤5%及所有资格成立。
分母退化、依赖不可接受或成本不闭合为证据不足；其他未满足阈值为未达改进条件。
软件失败返回非零；可解析但不足、未达标或支持的报告分别标状态，不能输出密码更安全。
批次摊销分布P99不是单次P99；混合窗口不能归属类别耗时，单次P99为不可获得。
软件夹具只测试实现；macOS接口记录不进入正式结果表，作者换目录复算不算第三方复现。
